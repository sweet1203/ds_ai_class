01

데이터 편향성이란 무엇일까?

교과서 214쪽 · 1 데이터 편향성 확인하기 ①

쉽게 말하면인공지능은 보여 준 데이터만큼만 배워요. 데이터가 어떤 쪽으로 치우쳐 모이면, 모델은 그 치우친 세상이 전부인 줄 알고 판단해요. 이것이 데이터 편향성이에요.

▶ 먼저 노트북 준비 셀부터 실행해 두기

  1. 아래 버튼으로 코랩 노트북을 열어요.
  2. 메뉴 런타임 → 런타임 유형 변경 → T4 GPU → 저장. 오늘은 학습을 두 번 해서 GPU가 꼭 필요해요.
  3. 준비 셀을 그대로 실행해요. 사진을 내려받고 산불 이미지 분류 모델(컬러)을 8 epoch 학습시켜요. GPU에서 1분 안팎 걸리니 기다리는 동안 아래를 읽어요.
코랩에서 노트북 열기 ↗노트북 파일 받기

코랩은 창을 닫으면 학습한 모델이 사라져요. 그래서 준비 셀이 「산불 이미지 분류하기」에서 한 일(데이터 내려받기 → CNN 모델 학습)을 한 번에 다시 해요. 준비 셀 출력에 fire non test1.jpg test2.jpg test3.jpg가 보이지 않으면 선생님께 알려 주세요.
GPU가 잡히지 않으면 준비 셀(과 02의 빨간색 건물 셀)만 실행하고, 03~04의 회색조 학습은 화면의 「셀 실행 흉내」로 따라가요. CPU로는 15 epoch가 10분 넘게 걸려요.
사진 출처: 교과서 제공 실습 데이터(수업용)

📰 「자율주행 자동차의 판단」

2016년 7월 미국에서 자율주행 자동차 모델의 첫 사망 사고가 발생했다. 자율주행 중 좌회전하는 트럭에 그대로 충돌하였기 때문이다. 이 사고의 원인은 하얀색 트럭을 「밝게 빛나고 있던 하늘」로 인식했기 때문이다.

자율주행의 인공지능은 도로 상황에 대한 데이터를 수집하여 모델을 학습시킨다. 그러나 데이터가 특정 조건에 한정되어 수집된다면 모델은 그 조건에서 운전하는 것을 배운 것과 같게 되어 이러한 사고를 일으킨다.

📖 데이터 편향성

데이터 수집 과정에서 특정 그룹이나 성향을 지닌 데이터가 다른 그룹이나 성향을 지닌 데이터보다 과도하게 포함된 상황을 「데이터 편향성」이라고 한다. 이는 인공지능 모델의 성능을 왜곡시키고, 예측 결과의 신뢰성을 떨어뜨릴 수 있다.
“데이터 편향은 인공지능 시스템의 문제이기도 하지만 사회의 불공정한 편향과 차별도 문제가 된다. 이를 예방하기 위해 사회 전반이 변화하고 있으며, 이러한 편향은 점점 줄어들 것이다.” (교과서 215쪽)
더 알아보기 · 다른 분야의 데이터 편향성 사례
  • 얼굴 인식 · 2018년 한 연구에서 얼굴 인식 소프트웨어가 피부색이 어두운 사람의 얼굴에서 오류율이 훨씬 높게 나왔다. 학습 데이터에 백인 남성 얼굴이 많고 흑인이나 여성의 데이터가 부족했기 때문이다.
  • 의료 · 2019년 미국의 한 의료 인공지능이 의료비 지출 기록으로 학습한 탓에, 그동안 의료비를 적게 썼던 아프리카계 미국인 환자에게 필요한 의료 서비스를 낮게 판단하는 문제가 발견되었다.

데이터의 편향이 사회 불평등을 키울 수 있어서, 다양한 데이터를 모아 균형 잡힌 데이터셋을 만드는 것이 중요해요. (「데이터 수집 · 편향성」에서 배운 정확성과 공정성을 떠올려 보세요.)

빨간색 건물로 편향성 확인하기

교과서 214쪽 · 1 데이터 편향성 확인하기 ②

쉽게 말하면산불 사진에는 빨간색·주황색이 아주 많아요. 그렇다면 모델이 불꽃이나 연기를 보는 게 아니라 「얼마나 빨간가」로 판단하고 있을지도 몰라요. 불이 없는 빨간색 건물로 시험해 보면 알 수 있어요.

📖 편향된 데이터로 데이터 편향성 확인하기

우리가 만든 화재 이미지 분류 모델은 데이터 편향성이 존재하지 않는 신뢰성 높은 모델일까? 산불 데이터를 살펴보면 불을 상징하는 빨간색이 많다는 것을 알 수 있으며, 따라서 산불 이미지 분류가 단순히 빨간색의 정도를 통해 이루어지는 것은 아닌지 의심할 수 있다.

img3 = Image.open(path + '/test3.jpg')     # 교과서: files.upload() 후 '/content/test3.jpg'
img_resize3 = img3.resize((400, 400))
test_img3 = image.img_to_array(img_resize3) / 255   # (더한 부분)
test_img3 = np.expand_dims(test_img3, axis = 0)
images3 = np.vstack([test_img3])
classes3 = model.predict(images3, batch_size = 10)
print(classes3[0])
if classes3[0][0] < 0.5:                # (고친 부분)
    print('Fire Image')
else:
    print('Non Fire Image')
교과서 결과 빨간색 건물 이미지인 test3.jpg 파일을 테스트해 본 결과, 단순한 빨간색 건물 이미지임에도 불구하고 산불 이미지로 판별했다. 따라서 우리가 만든 산불 이미지 분류 모델에도 학습 데이터에 편향성이 있었음을 알 수 있다.
÷255와 0.5 기준을 더한 까닭은 「산불 이미지 분류」의 새 이미지 평가와 같아요(학습 때와 같은 0~1 범위, 0.5보다 작으면 산불). 출력이 [3.1e-12]처럼 나오면 e-12는 소수점 아래 0이 11개인 아주 작은 수, 곧 거의 0이라 산불로 판별한 거예요. 내 노트북에서는 어떤 값이 나왔나요?

🎨 색만 보고 판별하면 어떻게 될까?

학습에 쓴 사진 324장마다 붉은 픽셀의 비율(빨강·주황으로 보이는 점이 사진의 몇 %인지)을 계산해 점으로 찍었어요. 「붉은 비율이 기준 이상이면 산불」이라는 아주 단순한 규칙을 만들어 보세요. 기준 막대를 끌거나, 슬라이더를 움직이거나, 막대를 누른 뒤 ←→ 키를 써요.

CNN이 실제로 이 규칙을 쓴다는 뜻은 아니에요. 하지만 색 하나만 봐도 학습 데이터를 이만큼 맞힐 수 있으니, 모델이 모양보다 쉬운 「색」이라는 지름길을 배우기 쉬워요. 붉은 픽셀 비율은 수업용 zip의 사진으로 직접 계산한 값이에요.

03

회색조로 바꾸어 편향 줄이기

교과서 215쪽 · 2 데이터 편향성 해결하기

쉽게 말하면모델이 색에 기대고 있다면, 아예 색을 없애 버리면 어떨까요? 사진을 회색조(흑백)로 바꾸면 밝기만 남아서, 모델은 빨간색 대신 불꽃의 모양, 연기의 결, 밝고 어두운 무늬 같은 다른 단서를 찾아야 해요.

📖 BGR2RGB → BGR2GRAY

앞서 빨간색 건물 이미지로 테스트한 결과, 산불 이미지로 잘못 분류하고 데이터 편향성이 있다는 것을 발견하였다. 이를 해결하기 위해 205쪽 코드에서 이미지 데이터의 색상을 모두 회색조로 전처리해 보자.

def read_img(file_path):
  img_arr = cv2.imread(file_path)
  return cv2.cvtColor(img_arr, cv2.COLOR_BGR2RGB)
→ 
def read_img(file_path):
  img_arr = cv2.imread(file_path)
  return cv2.cvtColor(img_arr, cv2.COLOR_BGR2GRAY)

RGB 형식은 세 가지 기본 색상 채널을 사용하는데, GRAY 형식으로 변환하면 색상 없이 휘도와 밝기 정보만 나타내도록 데이터가 단순화된다. 따라서 이미지를 BGR2GRAY로 변환하면 데이터의 편향성을 감소시킬 수 있고 모델의 학습 속도도 향상시킬 수 있다.

편향성 감소

색상 정보가 없으면 특정 색에 기대는 편향이 줄어, 모델이 형태나 패턴에 기반하여 학습하게 돕는다.

계산 효율성

채널이 3개 → 1개라 처리할 데이터가 1/3로 준다. 첫 합성곱층의 매개 변수도 448 → 160개로 줄어든다(전체 약 945만 개 중 일부라 효과는 조금).

잃는 정보

색이 꼭 필요한 단서였다면 그만큼 정보를 잃는다. 불꽃의 주황색도 함께 사라지므로 모델이 더 많이 학습해야 한다.

⚠️ 여기서 잠깐! read_img만 바꾸면 학습 데이터는 그대로 컬러예요

read_img는 사진을 화면에 보여 줄 때만 쓰는 함수예요. 모델이 학습하는 데이터는 flow_from_directory가 폴더에서 다시 읽어 오는데, 기본값이 컬러(color_mode = 'rgb')예요. 교과서 소스 노트북의 gray_model도 입력이 (400, 400, 3)이라 실제로는 컬러 사진으로 학습했어요. 정말 회색조로 학습하려면 세 곳을 바꿔요.

gray_generator = gray_datagen.flow_from_directory(
                 path, target_size = (400,400),
                 batch_size = 9, class_mode = 'binary',
                 color_mode = 'grayscale',     # ① 회색조로 읽기
                 seed = 3)
gray_model = tf.keras.models.Sequential([
      tf.keras.layers.Conv2D(16, (3, 3), activation = 'relu', input_shape = (400, 400, 1)),   # ② 채널 1개
      …(나머지 층은 같음)…
])
img_gray3 = img3.convert('L').resize((400, 400))   # ③ 테스트 사진도 회색조로

CNN 모델을 만들 때 model이 아니라 gray_model처럼 다른 이름을 쓰면 컬러 모델과 헷갈리지 않아요. 수업용 노트북은 이렇게 고쳐 두었어요. gray_model 셀에서 input_shape에 관한 경고(UserWarning)가 한 줄 나올 수 있는데, 오류가 아니라서 그대로 진행해요.

다시 학습하고 평가하기

교과서 216쪽 · 3 편향된 데이터로 성능 평가하기

쉽게 말하면색이라는 쉬운 단서가 사라졌으니 모델은 더 오래 배워야 해요. 그래서 학습 횟수를 8 → 15로 늘려요. 그다음 빨간색 건물을 다시 보여 줘요.

📖 학습 횟수 늘려 다시 학습하기

색상 특징이 없으므로 이미지 학습 단계에서 학습 횟수(epochs)를 더 늘려 준다.

history = gray_model.fit(gray_generator, steps_per_epoch = 36, epochs = 15, verbose = 1)   # 교과서: epochs = 8 → 15

회색조로 이미지 데이터를 변환한 후 충분히 학습한 산불 이미지 분류 모델로 빨간색 건물을 테스트해 본다. 수업에서는 진짜 산불 사진(test1.jpg)도 꼭 함께 테스트해요. 빨간 건물만 맞히고 진짜 산불을 놓친다면 편향이 풀린 것이 아니니까요.

classes4 = gray_model.predict(images4, batch_size = 10)   # images4: 회색조로 바꾼 test3
print(classes4[0])                # (고친 부분) 교과서: print(classes2[0])

데이터 편향성은 특정 그룹이나 성향의 데이터가 과도하게 포함된 상황이에요. 산불 사진은 붉은색이 많고, 산불이 아닌 사진은 거의 숲(초록)이라 모델이 빨간색 건물도 산불로 판단했어요.
BGR2GRAY로 회색조로 바꾸면 색 없이 밝기만 남아 모델이 형태·패턴을 보게 되고, 색 단서가 없으니 epochs를 8 → 15로 늘려요. 학습 데이터도 color_mode = 'grayscale'로 읽어야 정말 회색조로 학습해요.
회색조 모델은 빨간 건물을 맞혀도 진짜 산불을 놓칠 수 있어요(색 정보를 버린 대가). 단풍·노을·빨간 건물처럼 붉지만 산불이 아닌 사진을 더해 데이터의 균형을 맞추는 것이 편향을 줄이는 근본적인 방법이에요.
