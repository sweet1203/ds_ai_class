집을 지을 재료는 어디서 구할까?
기계학습에 가장 큰 영향을 주는 요소는 데이터예요. 집을 지을 때 필요한 재료를 구하는 방법이 다양하듯이, 기계학습을 적용한 문제 해결에 알맞은 데이터를 수집하는 방법도 다양해요. 직접 재거나 물어볼 수도 있고, 장치와 코드가 자동으로 모으게 할 수도 있고, 이미 모아 둔 데이터를 가져다 쓸 수도 있지요.

앞에서 본 기계학습 문제 해결 과정의 두 번째 단계가 데이터 수집이에요. 오늘은 세 가지 수집 방법을 하나씩 직접 해 보고, 문제에 따라 어떤 방법이 알맞은지 판단해 봐요.

01

관찰, 측정, 설문을 통한 수집 수동

교과서 62쪽 · 관찰과 측정, 질문과 설문지, 온라인 설문

쉽게 말하면사람이 직접 보고, 재고, 물어서 데이터를 모으는 방법이에요. 쉽고 간단하지만, 기계학습에 필요한 많은 양을 모으려면 시간과 노력이 많이 들어요.

📖 관찰하거나 직접 측정하기

기계학습에 필요한 데이터를 수집하는 가장 간단한 방법은 해당하는 데이터를 관찰하거나 직접 측정하는 것이다. 초기 데이터 분석 연구에서 사용된 데이터의 대부분은 직접 측정한 것이었다. 간단한 통계 처리를 위한 데이터는 이 방법으로 수집할 수 있지만, 기계학습에 필요한 데이터의 양은 훨씬 많으므로 많은 시간과 노력이 필요하다.

📖 질문하기 · 설문지

사람들의 태도나 의견, 의도, 행동의 동기 등의 데이터는 대상자에게 질문하는 방법으로 수집할 수 있는데, 여러 사람의 데이터가 필요하다면 설문지를 활용할 수 있다. 설문지를 활용하면 특정 문제에 대한 많은 데이터를 짧은 시간에 적은 비용으로 수집할 수 있다는 장점이 있다. 과거에는 설문지로 조사한 데이터를 다시 가공하여 이용했지만, 요즘은 사람들의 의견 수집과 데이터 가공이 동시에 이루어지는 온라인 설문을 많이 활용하고 있다.

📏

측정하여 데이터 수집

특별한 기술이나 능력이 없어도 데이터를 수집할 수 있다.

📝

질문하여 데이터 수집

사람들의 태도, 의견, 의도, 행동의 동기에 대한 데이터를 수집할 수 있다.

리커트 척도법 (62쪽): 설문 조사 같은 질문에 쓰는 응답 척도의 하나로, 응답자가 제시된 문장에 얼마나 동의하는지를 답하게 해요. 예) 「아이스크림은 아침 식사로 적합하다.」 1. 전혀 그렇지 않다 2. 그렇지 않다 3. 보통이다 4. 그렇다 5. 매우 그렇다

📲 온라인 설문 체험 · 응답이 곧바로 데이터가 돼요

「등교」에 관한 예시 설문에 답해 보세요. 「제출」을 누르면 내 응답이 아래 데이터 표의 한 줄이 되고, 요약이 바로 다시 계산돼요. 위 여섯 줄은 꾸며 낸 예시 응답이고, 내 응답은 이 화면에만 잠깐 보이고 어디에도 저장·전송되지 않아요.

02

자동화 장치와 코드를 활용한 수집 자동

교과서 63쪽 · 센서와 사물 인터넷, 검색어 데이터, 웹 크롤링

쉽게 말하면센서나 프로그램이 사람 대신 데이터를 정해진 때마다, 또는 실시간으로 모아 저장해요. 센서를 썼는지보다 사람의 개입 없이 모이고 저장되는지가 핵심이에요.

📖 자동화 장치로 데이터 수집

센서의 종류가 다양해지고 사물 인터넷 기술이 발달하면서 데이터를 수집하는 모습도 변하고 있다. 예를 들어 요즘 기상 데이터 수집은 특정 장소에 센서를 설치하고 매일 같은 시간에 센서로부터 전송되는 데이터를 저장하여 다양한 곳에 활용된다. 센서와 사물 인터넷 기술이 결합된 자동화 장치를 이용하면 일반인들도 카메라, 위치 센서, 열 센서, 압력 센서, 생체 센서, 습도 센서, 조도 센서와 사물 인터넷 기술을 활용하여 실시간으로 데이터를 수집할 수 있다.

사물 인터넷(IoT) (63쪽): 사물에 센서를 부착해 실시간으로 데이터를 주고받는 기술이나 환경. · 센서 측정: 온도계를 가지고 가서 매시간 측정하는 방식은 센서를 써도 수동이에요.

📖 자동화 코드로 데이터 수집

센서에 의해 측정되어 수집되는 데이터뿐만 아니라 인터넷에 업로드된 데이터와 사람들의 검색어도 데이터로 활용할 수 있다. 또한 인터넷에 분산되어 있는 데이터 중 특정 목적에 부합하는 데이터만을 찾아내는 웹 크롤링은 자동화 코드를 활용하여 데이터를 수집하는 방법 중 하나이다.

📡

자동화 장치로 데이터 수집

실시간으로 만들어지는 다양하고 방대한 데이터를 빠르게 수집할 수 있다.

공유 사이트를 이용한 수집

교과서 63쪽 · 공공 데이터 공유 사이트, 민간 데이터 공유 사이트

쉽게 말하면국가 기관이나 기업이 이미 모아서 공개한 데이터를 내려받아 쓰는 방법이에요. 내가 직접 모으기 어려운 큰 데이터도 구할 수 있어요.

📖 공공 데이터 공유

기계학습을 적용한 문제 해결에 대해 사회적 관심이 높아지면서 국가 기관이 보유하고 있는 공공 데이터를 공유할 수 있게 되었다. 공공 데이터 공유는 사회의 투명성을 높일 뿐만 아니라 사회 문제를 해결하는 데도 이용할 수 있으므로 여러 나라와 기업이 양질의 데이터를 공유하기 위해 노력하고 있다. 공공 기관이 운영하는 공공데이터포털과 같은 데이터 공유 사이트뿐 아니라 국내·외의 민간 기업에서도 데이터 공유 사이트를 운영하고 있다.

05

마무리

오늘 배운 것 정리 · 질문폼

관찰, 측정, 설문(수동)은 가장 간단한 수집 방법이다. 태도·의견·의도·동기는 질문으로 모으고, 설문지는 많은 데이터를 짧은 시간에 적은 비용으로 모은다. 다만 기계학습에 필요한 많은 양을 모으려면 시간과 노력이 많이 든다.
자동화 장치와 코드(자동)는 센서·사물 인터넷으로 실시간·연속 데이터를, 웹 크롤링 같은 코드로 인터넷의 방대한 데이터를 사람의 개입 없이 빠르게 모은다.
공유 사이트에서는 공공 기관과 민간 기업이 공개한 양질의 데이터를 쓸 수 있다. 공공 데이터 공유는 사회의 투명성을 높이고 사회 문제 해결에도 이용된다.
