쓰기 메모 4칸(`chefData`·`biasStage`·`fairVsAcc`·`biasPlan`) + 기록 1개(`planPick`) + 칩 1개. 퀴즈 10문항. 질문폼 1번 ← 01 분류 게임·`biasStage`, 2번 ← 02 시뮬레이션·`fairVsAcc`, 3번 ← 03 표·예시 답안·`biasPlan`.

**50분 흐름** — 도입(3분) 요리사 비유·좋은 데이터 메모 → 01(8분) 정의·3단계, 분류 게임, 메모 → 02(8분) 시뮬레이션으로 정확성·공정성 구분, 메모 → 03(9분) 4문제 수집 방법 고르기·예시 답안 비교, 메모(여기까지 28분 — 질문폼 근거를 앞에 모음) → 04(5분) Iris.csv 개수 세기, 빈칸·칩 → 05(7분) 속성 분류 게임, (나)/(다) 보기 → 06(6분) 전처리 4가지, 두 표 합치기 → 마무리(4분) 퀴즈 결과·질문폼(남은 시간이 부족하면 질문폼은 과제로).

**줄인 것** — 캐글 회원 가입·로그인은 수업 중에 하지 않고 Iris.csv·Iris1.csv를 화면에서 바로 받게 함(캐글 링크는 남김). 67쪽 코드는 노트북으로 실행할 수 있게 두되, 화면에 코드와 실행 결과를 함께 보여 줘 실행하지 않아도 따라올 수 있게 함. 코랩 `files.upload()`는 노트북에서 인터넷 주소로 바로 읽도록 바꿈(교과서 코드는 화면에 그대로). 61쪽 (나)·(다) 문제는 한 줄 요약으로만 다시 보여 줌.

**지어낸 것(예시 표시함)** — 01 분류 게임 상황 8개, 02 AI 스피커 시뮬레이션과 정확도 숫자(「설명을 위해 만든 예시」라고 화면에 적음), 03의 예시 답안은 교사용 교과서 예시 답안이라 「예시 답안」으로만 표시하고 쪽 번호를 달지 않음.

**확인할 점(교과서 모호한 곳)**
- 64쪽 정의 문장: 교사용 교과서는 「보이는 있는 것」(오탈자), 학생용 교과서는 「치우친 경향을 보이고 있는 것」 → 학생용 문장으로 씀(화면 01, 퀴즈 1-1).
- 64쪽은 「정확성이 떨어지고 공정성을 갖기 힘들다」만 말하고 두 말의 차이는 설명하지 않음. 02 화면의 구분(정확성 = 결과가 얼마나 맞는가, 공정성 = 틀리는 일이 특정 집단에 몰리지 않는가)은 질문폼 2번을 위해 덧붙인 풀이로, 「생각해 보기」로 표시함.
- 03 「과목 선택 검색 추이」 문제의 수집 방법: 예시 답안은 자동화 장치와 코드(63쪽 「사람들의 검색어도 데이터로 활용」·웹크롤링과 맞음). 펭귄 문제는 예시 답안이 공유 사이트지만 직접 측정도 가능해, 화면은 「예시 답안과 달라도 이유가 있으면 괜찮아요」로 안내.
- 65쪽 예시 답안 「종류별 개수에서 편향이 있다면 학습에 사용할 데이터의 수를 맞춘다」는 교사용 예시 답안 → 활동 결과 문장에만 녹여 씀.
- 66쪽 측주의 「신발 크기」는 이산형으로 분류되어 있어 그대로 따름. 「등급(1등급, 2등급, 3등급)」은 숫자가 들어 있어도 순위형(범주형).
- 66쪽 데이터 유형 도식, 67쪽 전처리 4가지, 60쪽 스케일링·인코딩 측주는 학생용 교과서에도 있음(검토에서 학생용 PDF로 확인) → 쪽수를 달아 씀. 61·64·65쪽 예시 답안은 교사용 → 「예시 답안」 표시만.
- 06 합치기 결과의 인덱스: `pd.concat`은 원래 인덱스를 유지해 Iris2 부분이 0부터 다시 시작함(실제 실행 결과와 같음). 이 점은 다음 시간(u2-preprocess-2) 이상치 제거 단계에서 다시 다룸.
- Iris1.csv·Iris2.csv는 cp949 인코딩. 노트북은 저장소 공개 주소(raw.githubusercontent.com)에서 읽으므로 **저장소에 올라간 뒤에야 코랩에서 열림**.

**검토 반영** — 05·06 제목에 「선생님과 함께 빠르게」 표시, 퀴즈 13 → 10문항(1-3 전처리 단계, 5-2 (다) 종속 변수, 6-2 concat 결과 뺌 — 질문폼은 64쪽만 묻기 때문). 64쪽 정의를 학생용 문장으로. 전처리 카드 「데이터 변환」 예를 60쪽 측주의 스케일링·인코딩으로 바꿈(「영문 속성 이름을 한글로」는 교과서의 변환 뜻과 달라 뺌). AI 스피커 시뮬레이션의 중간 구간 문장을 슬라이더 방향과 상관없게(「이 비율에서는 차이가 ○%p」). 「다음 시간」 표현 2곳(전처리 카드, 합치기 결과)을 순서와 상관없는 말로 바꿈.
