01

훈련 데이터와 테스트 데이터를 어떻게 준비할까?

교과서 76쪽 · 독립 변수와 종속 변수, 데이터 나누기

쉽게 말하면데이터를 공부용(훈련 데이터)과 시험용(테스트 데이터)으로 겹치지 않게 나눠요. 모델은 훈련 데이터로만 배우고, 한 번도 본 적 없는 테스트 데이터로 실력을 확인해요.

📖 독립 변수(X)와 종속 변수(y) 나누기

데이터 수집과 전처리가 끝나면 기계학습을 수행할 수 있다. 전처리된 데이터는 독립 변수(X)와 종속 변수(y)로 분리해야 한다. 독립 변수(X)에는 핵심 속성으로 추출한 「꽃잎 길이」, 「꽃잎 너비」 속성을, 종속 변수(y)에는 「종류」 속성을 넣는다.

X = df3[['꽃잎 길이', '꽃잎 너비']]  # 독립 변수(핵심 속성)
y = df3['종류']                      # 종속 변수

df3은 결측치와 이상치를 처리한 붓꽃 데이터(147송이)예요. 데이터프레임에서 여러 개의 열을 선택할 때는 대괄호([ ])를 겹쳐서 써요.

훈련 데이터

모델을 학습시키기 위해 사용하는 데이터이다. 기계학습을 통한 모델 생성에 사용한다.

테스트 데이터

훈련된 모델의 성능을 평가하기 위해 사용하는 데이터로, 모델이 이전에 본 적이 없는 데이터에 대한 성능을 측정한다.

전체 데이터
훈련 데이터 (60~80%)테스트 데이터 (20~40%)

이때 X와 y를 훈련 데이터와 테스트 데이터로 중복되지 않게 분리해야 한다. 일반적으로 훈련 데이터의 비율은 60~80% 정도로 하고 테스트 데이터의 비율은 20~40%로 정하지만, 준비한 데이터셋의 수량이나 정확도를 높이기 위해 비율을 조정하기도 한다.

from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size = 0.2,
                                                    random_state = 7)

해석 훈련 데이터와 테스트 데이터를 8:2로 랜덤하게 분리해 X_train, X_test, y_train, y_test에 저장한다. test_size 옵션을 0.2로 지정하면 훈련 데이터 80%, 테스트 데이터 20%로 나눈다는 의미이다.
더 알아보기 random_state에 숫자를 정해 두면 실행할 때마다 랜덤하게 나뉘는 결과가 달라지지 않아요.

✂️ 비율을 바꿔 나누어 보기 (교과서 붓꽃 데이터 147송이 · k-최근접 이웃, k = 5)

훈련 비율을 고르면 붓꽃이 훈련 데이터(색 점)와 테스트 데이터(테두리 점)로 나뉘어요. 숫자는 교과서 코드(random_state = 7)를 그대로 실행한 결과예요.

기계학습을 통한 모델 생성은 어떻게 할까?

교과서 77쪽 · 모델 생성, fit( ), 과적합과 과소적합

쉽게 말하면먼저 알고리즘으로 빈 모델을 만들고, fit( )에 훈련 데이터와 그 정답을 넣어 학습시켜요. 학습이 너무 지나치면 훈련 데이터에만 딱 맞고, 너무 모자라면 어디에도 잘 맞지 않아요.

📖 모델 만들고 학습시키기

기계학습 알고리즘은 종류가 다양하고 각 모델마다 데이터를 활용하여 학습하는 방식이 조금씩 다르다. 61쪽 (나) 문제인 붓꽃의 종류를 분류하는 모델에 k-최근접 이웃 알고리즘을 선정하기 위해 KNeighborsClassifier( ) 함수로 분류 모델을 생성하여 model 변수에 저장한다.

from sklearn.neighbors import KNeighborsClassifier
model = KNeighborsClassifier( )   # k-최근접 이웃 모델 생성
model.fit(X_train, y_train)       # 훈련 데이터와 훈련 데이터의 정답으로 학습
모델 객체.fit(훈련 데이터, 훈련 데이터의 정답)
X_train[[4.2, 1.2], [1.3, 0.3], [5.1, 1.8], …]y_train['버시컬러', '세토사', '버지니카', …]

여기서 생성한 모델은 사람에 비유하면 아직 학습하지 않은 뇌 구조에 해당한다. · 파라미터: 모델이 학습하는 동안 업데이트되는 변수로, 훈련 데이터에 적응하려고 시도하면서 최적의 값을 찾아내는 역할을 한다.

🤖 AI와 함께 지식 키우기 · 과적합과 과소적합

과적합(overfitting)은 기계학습에서 모델이 훈련 데이터에 너무 맞춰져서, 새로운 데이터나 실제 상황에서 성능이 나빠지는 현상을 말한다. 반면에 모델이 훈련 데이터의 패턴을 충분히 학습하지 못해 훈련 데이터와 실제 데이터 모두에 대해 성능이 낮아지는 현상을 과소적합(underfitting)이라고 한다.

🔬 더 알아보기 · k를 바꾸면 경계가 어떻게 달라질까? (예시 데이터)

두 무리가 구불구불한 경계로 나뉘고 일부는 섞여 있는 연습용 예시 데이터예요. 색 점은 훈련 데이터, 테두리 점은 테스트 데이터예요. k-최근접 이웃의 이웃의 수 k를 바꾸면 배경색(모델이 나누는 영역)이 어떻게 바뀌는지 보세요. 교과서 80쪽처럼 붓꽃 데이터에서는 k가 정확도에 큰 영향을 주지 않았지만, 데이터에 따라서는 크게 달라질 수 있어요.

03

학습 모델의 성능을 평가해 볼까?

교과서 78쪽 · 정확도, 혼동행렬(표 Ⅱ-5)

쉽게 말하면정확도는 「전체 중 몇 개를 맞혔나」예요. 하지만 무엇을 어떻게 틀렸는지는 알려 주지 않아요. 혼동행렬은 실젯값과 예측값을 표로 엇갈려 놓아 틀린 종류까지 보여 줘요.

📖 1 테스트 데이터를 사용하여 정확도 확인하기

정확도(accuracy)는 기계학습 모델의 평가 지표 중 하나로 모델의 예측 결과가 실제 정답과 얼마나 일치하는지를 평가하는 것이다. 사이킷런의 분류 모델에서 제공하는 score( ) 함수를 호출하여 측정하며, 이때 사용하는 데이터는 학습에 사용하지 않았던 테스트 데이터이다.

acc = model.score(X_test, y_test)               # 모델의 정확도를 계산하여 저장
print('테스트 데이터 점수: {:.3f}'.format(acc))   # 소수점 셋째 자리까지 출력
테스트 데이터 점수: 0.967

📖 2 혼동행렬로 성능 확인하기 (표 Ⅱ-5)

정확도는 가장 직관적으로 모델의 성능을 나타낼 수 있는 평가 지표이지만, 모델의 예측 중 잘못된 것이 얼마나 되며 무엇을 어떻게 잘못 추정하고 있는지 파악하기 어렵다. 혼동행렬(confusion matrix)을 활용하면 어떤 부분에 오류가 있는지 더욱 명확하게 파악할 수 있다.

예측값
참거짓
실젯값참TPFN
거짓FPTN
  • 참 긍정 TP (True Positive)
  • 참 부정 TN (True Negative)
  • 거짓 부정 FN (False Negative) · 실제 참인 것을 거짓으로 예측
  • 거짓 긍정 FP (False Positive) · 실제 거짓인 것을 참으로 예측

앞 글자(True/False)는 예측이 맞았는지, 뒤 글자(Positive/Negative)는 모델이 무엇이라고 예측했는지를 나타내요.

04

정확도가 같으면 같은 모델일까?

교과서 79쪽 · 표 Ⅱ-6·Ⅱ-7, 정밀도·재현율·F1-점수

쉽게 말하면질병 예측 모델과 스팸 메일 분류 모델은 정확도가 0.69로 똑같아요. 그런데 질병은 아픈 사람을 놓치는 것(FN)이, 스팸은 멀쩡한 메일을 스팸으로 버리는 것(FP)이 더 아파요. 그래서 문제마다 봐야 할 지표가 달라요.

📖 두 모델의 정확도

질병 예측(표 Ⅱ-6)과 스팸 메일 분류(표 Ⅱ-7) 혼동행렬은 모두 TP 9, FN 1, FP 30, TN 60이다. 정확도는 전체 데이터 중에서 정확하게 예측한 건수의 비율로 두 모델의 정확도는 모두 (9 + 60) / (9 + 60 + 30 + 1) = 0.69로 동일하다. 하지만 문제에 따라서 정확도뿐 아니라 잘못 분류한 FP, FN의 숫자에 대한 고려가 필요할 때가 있다.

🩺

질병 예측 모델

실제 질병인데 질병이 아니라고 예측하는 것은 사람의 생명과 직접 관련된 문제이기 때문에 정확도뿐만 아니라 FN에 대한 고려가 필요하다.

📧

스팸 메일 분류 모델

스팸이 아닌데 스팸이라고 분류하여 중요한 메일을 보지 못하게 되면 곤란한 일이 발생할 수 있으므로 FP가 중요한 지표가 될 수 있다.

🤖 AI와 함께 지식 키우기 · 분류 모델의 평가 지표

해결하고자 하는 문제에 따라 모델의 성능을 평가하는 적절한 평가 지표를 적용하는 것이 중요하다.

정확도(TP+TN) / (TP+TN+FP+FN)전체 중 정확하게 예측한 비율
정밀도(precision)TP / (TP+FP)모델이 긍정으로 예측한 것 중 실제로 긍정인 비율. 스팸 메일 분류에서는 정밀도가 중요하다.
재현율(recall)TP / (TP+FN)실제로 긍정인 데이터 중에서 모델이 긍정으로 정확하게 예측한 비율. 질병 예측 분류에서는 재현율이 중요하다.
F1-점수2 × 정밀도 × 재현율 / (정밀도 + 재현율)정밀도와 재현율의 조화평균. 두 지표는 서로 상충 관계이므로 균형을 찾아야 할 때 사용한다.

🧮 혼동행렬 계산기

오늘 배운 것 정리 · 질문폼

데이터는 훈련 데이터(모델 생성)와 테스트 데이터(성능 평가)로 겹치지 않게 나눈다. 테스트 데이터는 모델이 이전에 본 적이 없는 데이터여야 성능을 믿을 수 있다.
정확도는 전체 중 맞힌 비율이고, 혼동행렬은 TP·TN·FP·FN으로 무엇을 어떻게 틀렸는지 보여 준다. 정밀도 = TP/(TP+FP), 재현율 = TP/(TP+FN), F1-점수는 둘의 조화평균이다.
정확도가 같아도 문제에 따라 봐야 할 오류가 다르다. 질병 예측은 FN·재현율, 스팸 분류는 FP·정밀도가 중요하다. 여러 클래스는 기준 클래스를 정해 2×2로 바꾸어 평가한다.
