쓰기 메모 4칸(`naviPlan`·`riverWay`·`jugState`·`blindWhy`) + 칩 1개. 퀴즈 13문항. 질문폼 1번 ← 03 퍼즐·기록표·`riverWay`, 2번 ← 04 물통 퍼즐·`jugState`, 3번 ← 04 「컴퓨터라면?」·05 계산기·`blindWhy`.

**50분 흐름** — 도입(3분) 내비게이션 이야기·학습 계획 → 01(6분) 그래프·트리, 4-queen 해답 하나 찾기 → 02(8분) 탐색의 종류, 그림 Ⅰ-10 트리로 목표 K 재생 + 목표 하나 바꿔 비교 → **03(17분 무렵 시작, 10분)** 강 건너기를 직접 풀고 교과서 트리와 비교, 메모 → **04(27분 무렵 시작, 10분)** 물통 퍼즐, 컴퓨터 풀이와 비교, 메모 → 05(5분) 비교표·빈칸, 계산기는 선생님이 시연 → 마무리(8분) 퀴즈 결과 확인 후 질문폼. 질문폼 근거가 되는 03·04는 30분 안에 닿도록 앞 화면을 짧게 잡음.

**줄인 것** — 4-queen은 해답 하나로 끝(두 번째 해답은 시간이 남을 때만). 02 재생은 목표 K 한 번 + 목표 하나 바꾸기로 제한. 05 계산기는 접어 두고 선생님 시연. 30쪽 스스로 해결하기(5-queen 탐색 트리 그리기·친구와 수행)는 웹 사이트 링크만 두고 선택 활동으로. 32·35쪽 스스로 해결하기(코드 실행·새 트리 구성)는 코드와 실행 결과를 펼쳐 보기로만 보여 주고 노트북 파일은 넣지 않음(교과서 QR 자료). 28쪽 학습 계획 ②·③은 짝과 말로만. 탐색 기록장(스프레드시트)은 화면의 자동 기록표로 대신함.

**확인할 점** — 그림 Ⅰ-10·Ⅰ-12의 「목표 상태」 표시는 레이아웃상 K 옆에 있어 K를 기본 목표로 둠(두 탐색 경로 모두 K에서 끝나는 것과 맞음). 그림 Ⅰ-11·Ⅰ-13에서 13(늑대를 옮긴다)과 14(양배추를 옮긴다)는 같은 상태(s | fcw)로 이어지게 그려져 있어 그대로 한 노드로 그림. 4-queen 「왼쪽 목표 상태」는 그림으로만 정해져 있어 두 해답을 모두 목표로 인정. 물통 문제의 목표는 5L 물통에 4L(교과서 QR 참고 자료의 (4, 3)·(4, 0)과 같음). DFS 「되돌아갈 길」 목록은 교과서 용어에 없는 「스택」이라는 말은 쓰지 않고 풀어서 씀(BFS의 큐는 35쪽 보충 자료에 있음).

**검토 반영** — 퀴즈 해설에서 보기 위치를 가리키는 말을 보기 내용으로 바꿈(QUIZ[2][1]·[2][2]). 05의 「맹목적 탐색은 답이 있으면 찾아 주지만」에 조건(방문한 상태를 다시 가지 않고 모든 상태를 차례로 볼 때)과 33쪽 깊이 우선 탐색 주의점을 붙임. 퀴즈 5-2 해설 쪽수를 32·34·35쪽으로. 4-queen 트리 노드를 눌러 옮겨 가는 것은 「되돌아가기」 횟수에 넣지 않음(버튼으로 한 단계 되돌아갈 때만 셈). 표지 「배우고 나면 할 수 있는 것」을 29쪽 학습 목표 두 문장으로. 마무리 질문폼 3번 문장을 forms.json에 맞춤.
