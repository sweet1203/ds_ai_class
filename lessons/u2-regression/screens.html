행마다 종류를 바꿔 보고, 「get_dummies 실행」을 눌러 표가 어떻게 바뀌는지 보세요.

🔎 더 알아보기 · 세토사 = 1, 버시컬러 = 2, 버지니카 = 3으로 번호만 붙이면 안 될까?

번호를 붙여도 오류는 사라져요. 하지만 선형 회귀는 그 숫자에 가중치를 곱하므로, 모델은 버지니카(3)가 세토사(1)의 세 배이고 버시컬러(2)는 그 사이 어딘가에 있는 것처럼 계산해요. 종류에는 그런 크기나 순서가 없는데 숫자가 가짜 관계를 만들어 버리지요.

원-핫 인코딩은 종류마다 「이 종류인가(1), 아닌가(0)」를 나타내는 속성을 따로 만들어요. 그래서 모델이 종류마다 다른 가중치를 배울 수 있고, 종류 사이에 없는 크기 관계는 생기지 않아요.

03

성능 평가 · MSE와 R²

교과서 87쪽 · 1-④ 기울기와 절편, 2 성능 평가

쉽게 말하면숫자를 예측하는 모델은 「맞았다/틀렸다」로 채점하기 어려워요. 4.9를 4.91로 예측해도 「틀린」 것이 되니까요. 그래서 회귀 모델은 얼마나 가깝게 예측했는지를 재는 MSE와 R²로 평가해요.

④ 선형 회귀 모델의 기울기와 절편 찾기

print('선형 회귀 가중치: {}'.format(model.coef_))       # coef_: 가중치(기울기)
print('선형 회귀 편향: {}'.format(model.intercept_))    # intercept_: 편향(절편)
선형 회귀 가중치: [ 0.5851811   0.78889363 -0.31301472 -0.07307218 -0.36541193  0.43848411]
선형 회귀 편향: 1.4936806502641469

편향의 끝자리는 실행 환경마다 조금 다를 수 있어요(교과서 원본 노트북은 …495). 교과서 87쪽에는 가중치가 [[ … ]], 편향이 [ … ]처럼 대괄호가 한 겹 더 실려 있지만, 이 노트북에서는 위처럼 나와요. 값은 같아요.

가중치 6개는 X의 여섯 속성(꽃받침 너비, 꽃잎 길이, 꽃잎 너비, 종류_버시컬러, 종류_버지니카, 종류_세토사)에 하나씩 곱하는 수예요. 꽃잎 길이의 가중치 0.789는 「다른 값은 그대로 두고 꽃잎 길이만 1 늘리면 예측한 꽃받침 길이가 약 0.789 는다」는 뜻이에요.

더 알아보기 · 가중치는 입력 데이터 또는 특성에 대한 중요성을 나타내는 값이고, 편향은 모델의 출력값을 조정하는 상수예요. 오차는 모델의 예측값과 실젯값 사이의 차이로, 오차가 작을수록 모델이 정확한 예측을 하고 있음을 나타내요.

📉

평균제곱오차 (MSE: Mean Squared Error)

실젯값과 예측값 사이의 오차를 제곱하여 평균을 구한 것으로, 0에 가까울수록 성능이 우수하다.

오차를 제곱하므로 + 오차와 − 오차가 서로 지워지지 않고, 크게 빗나간 예측일수록 더 크게 반영돼요.
📈

R² (R-Squared) · 결정 계수

독립 변수가 종속 변수를 얼마만큼 설명해 주는지를 나타내는 비율로, 1에 가까울수록 성능이 우수하다.

01에서 평균선(모두 평균으로 예측)의 R²는 0, 최적 직선은 0.76이었어요.

2 성능 평가 코드와 실행 결과

from sklearn.metrics import r2_score            # 회귀 모델 성능 지표 모듈
y_pred = model.predict(X_test)                  # 테스트 데이터에 대한 예측값
r2 = r2_score(y_test, y_pred)                   # 결정 계수
print('결정 계수 R2: ', r2)

from sklearn.metrics import mean_squared_error  # (교과서 코드에 더한 부분)
mse = mean_squared_error(y_test, y_pred)        # 평균제곱오차
print('평균제곱오차 MSE: ', mse)
결정 계수 R2:  0.7854413960608994
평균제곱오차 MSE:  0.11558748791097

교과서 87쪽에는 R²가 1.0으로 실려 있지만, 같은 코드와 데이터로 실행하면 약 0.785가 나와요. 노트북에서 내가 얻은 값을 확인해 보세요.

🧮 정확도로 채점하면 어떻게 될까?

테스트 데이터 30개 중 5개를 골랐어요. 붓꽃 분류(k-최근접 이웃)에서는 정확도(전체 데이터 중에서 정확하게 예측한 건수의 비율, 78쪽)로 평가했지요. 버튼을 눌러 세 가지 방법으로 채점해 보세요.

마무리

오늘 배운 것 정리 · 질문폼

선형 회귀는 실젯값과 예측값의 차이인 오차를 최소화하는 직선(식)을 찾는다. 모르는 꽃받침 길이처럼 수치형 값을 예측하는 회귀 문제에 쓴다.
LinearRegression의 독립 변수에는 범주형 데이터를 쓸 수 없어 could not convert string to float 오류가 난다. 원-핫 인코딩으로 종류를 범주 수만큼의 0·1 속성으로 바꾸면 학습할 수 있다.
회귀 모델은 MSE(오차 제곱의 평균, 0에 가까울수록 우수)와 R²(설명하는 비율, 1에 가까울수록 우수)로 평가한다. 예측이 정확히 같은지가 아니라 얼마나 가까운지를 재기 때문이다.
