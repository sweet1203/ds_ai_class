2019년 가을 호주에서 사상 최악의 산불이 나서 약 1,860만 헥타르, 대한민국 국토 면적의 85%에 해당하는 땅이 타 버렸어요. 우리나라도 2004년 4월 강원도 동해안을 따라 번진 산불로 23,794 헥타르(서울 종로구의 10배)가 피해를 입었어요. 지구 온난화와 기상 이변으로 대형 산불은 점점 잦아지고 있어요.

오늘은 산불 사진과 산불이 아닌 사진을 모아 컴퓨터가 구별하도록 학습시키는 이미지 분류 프로젝트를 처음부터 끝까지 해 봐요. 사진처럼 형식이 정해지지 않은 비정형 데이터는 합성곱 신경망(CNN)으로 학습시켜요.

03

알고리즘 선정과 CNN 모델 만들기

교과서 208~209쪽 · 프로젝트 수행 과정 5단계, 6단계 ①

쉽게 말하면사진 분류에는 합성곱 신경망(CNN)을 써요. CNN은 사진 전체를 한꺼번에 보기보다 작은 부분을 보며 이웃한 픽셀끼리의 관계(선, 무늬, 불꽃 모양)를 찾고(합성곱층), 크기를 줄여 중요한 것만 남겨요(풀링층). 이것을 세 번 되풀이한 뒤 마지막에 산불인지 판단해요.

📖 5 알고리즘 선정

산불 이미지 데이터나 산불이 아닌 이미지 데이터와 같은 비정형 데이터를 분류하기 위해 합성곱 신경망(CNN: Convolution Neural Networks) 딥러닝 모델을 활용한다. CNN은 딥러닝에서 이미지 또는 영상 데이터를 처리할 때 사용하며, 주요 구성 요소는 컨볼루션과 풀링이다.

컨볼루션(convolution) · 합성곱층

입력 데이터와 필터(커널) 간의 합성곱 연산을 통해 특징을 추출한다. 같은 크기의 두 행렬을 포개어 같은 위치의 값끼리 곱하여 모두 더한다.

풀링(pooling) · 풀링층

입력 데이터의 공간 크기를 줄여 중요한 정보를 보존한다. 지정한 크기에서 최댓값만 가져오는 최대 풀링, 평균값을 가져오는 평균 풀링이 있다.

📖 6 모델 학습 · ① CNN 모델 생성하기

텐서플로 라이브러리를 불러오고, 계층(layer)을 순서대로 쌓는 Sequential 모델로 CNN을 만든다. 3개의 합성곱층과 풀링층을 지난 뒤 Flatten 계층에서 1차원 배열로 바꾸고, 마지막에 2개의 층(Dense)으로 판단한다.

import tensorflow as tf
model = tf.keras.models.Sequential([
      tf.keras.layers.Conv2D(16, (3, 3), activation = 'relu', input_shape = (400, 400, 3)),
      tf.keras.layers.MaxPool2D(2, 2),
      tf.keras.layers.Conv2D(32, (3, 3), activation = 'relu'),
      tf.keras.layers.MaxPool2D(2, 2),
      tf.keras.layers.Conv2D(32, (3, 3), activation = 'relu'),
      tf.keras.layers.MaxPool2D(2, 2),
      tf.keras.layers.Flatten(),
      tf.keras.layers.Dense(128, activation = 'relu'),
      tf.keras.layers.Dense(1, activation = 'sigmoid')
])
model.summary()

Conv2D(16, (3, 3)): 3×3 필터 16개 · MaxPool2D(2, 2): 2×2 최대 풀링 · Dense(1, activation = 'sigmoid'): 0~1 사이의 값 하나를 내는 마지막 층
Dense = 완전 연결층: 앞 층의 모든 값이 이 층의 모든 뉴런과 연결된 층이에요.

🧱 층을 지나며 모양이 어떻게 바뀔까?

층을 누르거나 「다음 층 ▶」을 눌러 따라가 보세요. summary( )의 Output Shape(출력값의 형태)와 Param #(매개 변수의 수)가 어떻게 계산되는지 나와요.

💻 코랩을 못 열 때 · 셀 실행 흉내 ⑦

코랩에서 이 셀을 실행하면 input_shape에 관한 경고(UserWarning)가 한 줄 나올 수 있어요. 오류가 아니라서 그대로 진행해요.

해석 각각의 계층에서 Output Shape를 알아볼 수 있다. Flatten 계층에서 3차원이던 데이터가 73,728개의 1차원 형태로 바뀐다. Param은 parameter(매개 변수)의 약자로, 학습할 때 알고리즘이 스스로 바꾸어 가는 값(가중치와 편향)이다. 이 모델 전체가 학습하는 매개 변수는 9,451,777개이다.
교과서 209쪽 실행 결과에는 Flatten 147,456개, 18,898,209개로 실려 있어요. 이 숫자는 세 번째 합성곱층의 필터를 64개로 했을 때의 결과예요(위 체험의 「더 알아보기」에서 「필터 64」를 눌러 확인). 교과서 코드(필터 32개)를 실행하면 73,728개, 9,451,777개가 나와요.

📖 3 새로운 이미지 데이터로 이미지 학습 모델 평가하기

교과서는 생성형 인공지능으로 산불 이미지를 만들어 files.upload()로 올렸어요. 수업용 zip 안에 이 사진들이 들어 있어서 바로 열면 돼요. PIL(Python Imaging Library)은 이미지 열기, 조작, 저장 등 이미지를 분석하고 처리하는 라이브러리예요.

from PIL import Image
img1 = Image.open(path + '/test1.jpg')     # 교과서: Image.open('/content/test1.jpg')

from tensorflow.keras.preprocessing import image
import numpy as np
img_resize1 = img1.resize((400,400))                 # ① 크기를 (400, 400)으로
test_img1 = image.img_to_array(img_resize1) / 255    # ② 숫자 배열로 + (더한 부분) 0~1로 정규화
test_img1 = np.expand_dims(test_img1, axis = 0)      # ③ 테스트 결과를 저장할 공간(차원) 만들기
images1 = np.vstack([test_img1])                     # ④ 테스트에 알맞게 배열 변환

400×400→img_to_array
(400, 400, 3)→÷ 255
0~1→expand_dims

classes1 = model.predict(images1, batch_size = 10)
print(classes1[0])
if classes1[0][0] < 0.5:          # (고친 부분) 교과서: if classes1[0]==0:
    print('Fire Image')

출력이 [1.6e-14]처럼 나오면 e-14는 「× 10의 −14제곱」, 곧 소수점 아래 0이 13개인 아주 작은 수예요. 거의 0이라서 산불 이미지예요.

🔧 교과서 코드와 다르게 쓴 두 줄

① / 255를 더한 까닭 학습할 때는 rescale = 1/255로 0~1 값을 썼어요. 새 사진도 똑같이 255로 나누어야 모델이 배운 것과 같은 범위의 숫자를 받아요. 교과서 코드는 이 줄이 빠져서 0~255 값이 그대로 들어가, 결과가 [0.]이나 [1.]처럼 끝까지 쏠려 나왔어요.

② 0.5를 기준으로 나눈 까닭 시그모이드 출력은 0.03, 0.97처럼 0과 1 사이의 값이에요. == 0으로 비교하면 0.03도 「0이 아님」이 되어 버려요. 그래서 0.5보다 작으면 산불(fire = 0), 크면 산불 아님(non = 1)으로 판단해요.
