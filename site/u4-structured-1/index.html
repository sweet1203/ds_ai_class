인공지능은 기대 수명을
어떻게 예측할까?

핵심 아이디어
세계보건기구(WHO)가 세계보건관측소(GHO)의 데이터를 바탕으로 발표한 2020년 기준 세계 기대 수명은 73.2세로, 2000년 66.5세보다 6.7세 높아졌어요. 우리나라는 84.4세로 12위예요. 그런데 기대 수명이 가장 높은 나라는 85.4세, 가장 낮은 나라는 54.3세예요. 나라마다 건강과 경제 수준, 문화·지리적 특성, 의료 시스템, 교육 수준 등이 다르기 때문이에요.

오늘은 WHO의 기대 수명 데이터로 기대 수명을 예측하는 인공지능 프로젝트를 시작해요. 프로젝트 수행 과정 8단계 중 문제 정의 → 데이터 수집 → 데이터 전처리 → 데이터 시각화 및 분석까지 코랩에서 직접 해 봐요.

03

데이터 전처리

교과서 193쪽 · 결측치 확인하기, 결측치 제거하기, 범주형 데이터를 숫자로

쉽게 말하면비어 있는 칸(결측치)이 있으면 모델이 학습할 수 없어요. 그래서 결측치를 확인하고 지우고, 글자로 된 Status(개발도상국·선진국)는 0과 1로 바꿔요. 그런데 지우면 무엇이 함께 사라지는지도 봐야 해요.
❶

결측치 확인하기

df.shape → (2938, 22)
df.isna().sum() → 속성별 결측치 개수

❷

결측치 제거하기

df = df.dropna()
결측치가 있는 행을 삭제하고 isna().sum()으로 모두 0인지 확인

❸

범주형 데이터를 숫자로

astype(object)로 Status를 범주형으로, replace({'Developing': 0, 'Developed': 1})

문자로 된 데이터를 학습할 수 없으므로 0과 1의 숫자로 바꿔 주는 작업을 한다. Status는 이미 object라 astype 줄은 생략할 수 있어요. 코랩에서 replace를 실행하면 분홍색 FutureWarning이 뜰 수 있는데, 오류가 아니에요.

🧪 결측치 처리 실험실

막대는 isna().sum() 결과예요. 그대로 dropna()를 하면 결측치가 하나라도 있는 행이 모두 지워져요. 결측치가 많은 속성을 눌러 「속성 전체를 먼저 지우기」(68쪽 결측치 처리 방법 (가))를 골라 보고, 남는 데이터가 어떻게 달라지는지 비교해 보세요.

✍️ 생각 정리

생각해 보기 · 데이터를 그대로 믿기 전에: 이 데이터에서 대한민국(Republic of Korea)은 Status가 「Developing(개발도상국)」으로 적혀 있어요. 또 Polio(소아마비 예방 접종률)가 20% 미만인 98행은 값이 모두 3~9뿐이라, 실제 접종률이라기보다 입력 오류일 가능성이 커요. 확인할 점은 없을까요?

오늘 배운 것 정리 · 질문폼

프로젝트는 문제 정의부터 시작한다. SDGs 3번(건강한 삶 보장과 복지 증진)을 위해 측정 지표인 기대 수명을 예측하는 인공지능 모델을 만들기로 정했다.
info()·isna().sum()으로 데이터를 확인하고 dropna()로 결측치를 지웠다. 2,938행이 1,649행으로 줄고 대한민국을 포함한 60개 나라가 빠졌으므로, 전처리 방법은 남는 데이터까지 살펴보고 골라야 한다.
히스토그램·히트맵·산점도·바이올린 그래프로 보니 교육 기간·소득(자원 소득에 대한 국가 개발 정도)은 기대 수명과 양의 상관관계, 성인 사망률·HIV/AIDS는 음의 상관관계가 크고, 인구수는 관계가 거의 없었다.

  1. 기대 수명 데이터에 dropna()를 실행하자 2,938행이 1,649행으로 줄고, 대한민국을 포함한 60개 나라의 데이터가 모두 사라졌습니다. 결측치가 있는 행을 지우는 방법과 결측치가 많은 속성을 먼저 지우는 방법을 비교해, 기대 수명을 예측하는 모델에는 어떤 방법이 더 나을지 실험 결과를 근거로 쓰세요.
  2. 히스토그램, 히트맵, 산점도, 바이올린 그래프 중 한 가지 시각화 방법을 골라 기대 수명에 영향을 미치는 속성을 찾아보았습니다. 고른 방법과 찾은 속성을 쓰고, 그래프의 어떤 모습을 보고 그렇게 판단했는지 설명하세요.
