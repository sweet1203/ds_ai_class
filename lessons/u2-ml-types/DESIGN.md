**확인할 점(교과서 모호한 곳)**
- 지도학습의 두 갈래를 74쪽은 「분류 / **예측**」, 61쪽 (다)와 85쪽은 「**회귀**」라 부름. 질문폼은 「회귀」. 화면은 「예측(회귀)」로 함께 적음.
- 부록 224쪽은 콜레라 활동을 「비지도학습」으로 해결한다고 하지만, 실린 코드는 k-평균이 아니라 **환자마다 가장 가까운 펌프를 찾아 색칠**하는 것(cdist → argmin)임. 화면은 교과서 코드 순서(①~③)를 그대로 따르고, 「펌프 위치를 모르는 채로 묶기」는 74쪽 옆단의 군집 알고리즘(k-평균)으로 ④ 더 해 보기로 따로 둠.
- 부록 224쪽 글의 오류: 위치를 「경도 54.5149, 위도 –.1348」로 적었으나 코드는 [51.5149, -0.1348](위도, 경도 순)을 씀. 「1852년」 콜레라 대유행이라 적었으나 존 스노의 소호 지역 조사는 일반적으로 1854년으로 알려짐. 코드 주석 「최댓값의 위치들」(argmin은 최솟값), `scipy.spatial.distancet`·`folium.map`·`interrow` 등 오타. 화면에는 연도·좌표를 쓰지 않고 「19세기 영국」으로만 씀(부록 글과 같은 표현).
- heart.csv의 output(0/1) 뜻은 교과서에 없음(캐글 설명: 1 = 발병 가능성 높음). 화면은 「발병 가능성 높음(1) / 낮음(0)」으로 쓰고 **예시 데이터**임을 밝힘. 의학적 해석은 하지 않음.
- 주택 가격 모델 식은 USA_Housing 선형 회귀에서 흔히 나오는 계수와 비슷한 크기로 만든 **예시 식**(평균 소득 1달러당 약 21.5달러, 방 1개당 약 12만 2천 달러, 나머지 속성은 평균값으로 고정). 실습 결과와 다를 수 있다고 화면에 적음.
- 그림 Ⅱ-4의 새로운 데이터 위치는 (꽃받침 길이 5.6, 너비 2.9)(검토 반영: 처음엔 5.75로 읽었음). Iris1.csv로 계산하면 k=5 이웃은 (5.6, 2.9)·(5.6, 3.0)×2·(5.7, 2.9) 버시컬러 4 + (5.6, 2.8) 버지니카 1로 그림과 같고, 5위와 6위(0.141)의 거리가 달라 동점 문제 없음. 다른 위치에서 같은 거리의 점이 겹치면 데이터 순서가 앞선 점을 먼저 셈(화면에 안내).
