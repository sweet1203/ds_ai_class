# 수행평가 아이디어 모음

학기 초 평가계획을 세울 때 여기서 고르고, 고른 것만 그 학기에 안내 페이지·연습 차시·활동지를 만든다.
채점 기준 상세·현장 문항은 비공개 저장소에 둔다.

| # | 아이디어 | 단원 | 도구 | 운영 기록 |
|---|---|---|---|---|
| A | 데이터 전처리·모델 분석 — 학생마다 다른 주제 CSV, 결측·이상치 → 핵심 변수 → 의사결정나무 → 혼동행렬 해석 | Ⅱ-1 | 파이썬/코랩 또는 붙여넣기 차단 웹앱 | 2026-2 수행① |
| B | ML4Kids 문제 해결 프로젝트 — SDGs 문제 정의 → 데이터 → 학습·테스트 → 개선 전후 비교 → Scratch | Ⅳ | ML4Kids · Scratch | 2026-2 수행② |
| C | 탐색 알고리즘 설계 — 미로·퍼즐을 상태 공간으로, 너비·깊이·A* 비교 기록 | Ⅰ | 탐색 기록장 | |
| D | 규칙 기반 판단 시스템 — 지식 표현 + 규칙으로 추천·진단, 한계 분석 | Ⅰ | 표·순서도·파이썬 | |
