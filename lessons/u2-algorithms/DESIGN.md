쓰기 메모 3칸(`algoDiff`·`treeGood`·`myData`) + 칩 1개. 퀴즈 11문항. 질문폼 1번 ← 01 체험·`algoDiff`, 2번 ← 02 트리 따라가기·`treeGood`, 3번 ← 04 분류 게임·85쪽 표·`myData`.

**50분 흐름** — 도입(3분) 야구부 이야기 → 01(12분) 두 슬라이더로 「숫자 답 vs 0/1 답」 비교, 메모 → 02(10분) 트리 따라가기, 14번 정하기, 메모 → 03(9분) SVM 그림은 설명만, k-평균은 교과서 위치에서 한 번 끝까지 + 다른 위치 한 번 → 04(10분) 분류 게임, 85쪽 표, 메모 → 마무리(6분) 퀴즈 결과 확인 후 질문폼.

**줄인 것** — 서포트 벡터 머신은 체험 없이 그림과 정의만(교과서도 개념 소개 수준, 지도 TIP 「너무 깊이 있는 학습보다 핵심적인 내용 소개」). 85쪽 주요 코드는 펼쳐 보기로만(실습은 다음 시간 선형 회귀 실습에서). k-최근접 이웃은 75쪽에서 배운 내용을 카드 하나로 다시 보기.

**만든 값(예시) 표시** — 표 Ⅱ-8은 14명 중 6명(1·2·3·12·13·14번)만 실려 있음. 나머지 8명의 (타율, 방어율)은 그림 Ⅱ-11·Ⅱ-12의 점을 어림해 읽은 값이고, 화면에 「그림에서 어림해 읽은 값」이라고 적음. 01의 회귀선은 그림 Ⅱ-7의 점(14, 0)을 뺀 12점을 어림해 읽어 최소제곱으로 구한 직선(y ≈ 0.0158x + 0.066), S자 곡선은 0.300에서 확률 0.5가 되도록 만든 예시 곡선. 04 분류 게임의 예시 3문제는 「예시」 표시.

**계산 확인** — 트리: 1번(0.122, 2.43)·2번(0.224, 2.42)·3번(0.145, 2.41) → 중간 투수, 12·13번 → 타자, 14번(0.250, 3.10) → 「타율 > 0.250」이 아니므로 아니요 → 방어율 3.10 > 2.0 → 중간 투수. 그림 값을 넣으면 타율 > 0.250이 7명, 나머지 7명 중 방어율 > 2.0이 5명, 마(1.30)·선(0.12) 각 1명으로 그림 Ⅱ-10의 샘플 수(14·7·7·5·2·1·1)와 맞음. k-평균: 거리는 그래프 눈금 기준(타율 ÷ 0.45, 방어율 ÷ 5)으로 잼. 교과서 그림과 비슷한 시작 위치 (0.12, 2.4)·(0.30, 4.0)·(0.20, 0.5) → 2번 만에 종료, 중심 ■(0.162, 2.59)·◆(0.309, 3.38)·▲(0.184, 0.71), 묶음은 {중간·중 4명} {타자 7명 + 14번} {마·선} — 그림 Ⅱ-12와 같음. 다른 시작 위치 (0.10, 1.0)·(0.20, 4.5)·(0.40, 1.0) → {투수 6명} {타자 5명 + 14번} {타자 2명}으로 다르게 끝남. 눈금을 맞추지 않은 원래 값으로 거리를 재면 방어율만으로 묶여 그림과 달라짐(그래서 눈금 기준으로 잼).

**교과서에서 애매한 점** — ① 82쪽 본문은 「14번 선수의 연습 시간을 알면 예상되는 타율을 예측」이라 하지만 표 Ⅱ-8에는 14번의 타율(0.250)이 있고 포지션이 비어 있음. 그림 Ⅱ-7에는 (14, 0) 점이 따로 찍혀 있음 → 회귀선 체험에서는 14번 이야기를 빼고, 14번은 02에서 「포지션을 트리로 정하기」로 씀. ② 83쪽 본문의 예시 질문은 「타율이 0.250 이상인가?」, 그림 Ⅱ-10과 설명 상자는 「타율 > 0.250」(초과) → 화면은 그림 기준(초과)으로 하고, 14번(0.250)에서 두 기준의 결과가 달라진다는 점을 짚음. ③ 설명 상자는 「선발 또는 마무리 투수(방어율 1.0 초과 2.0 이하)」, 그림의 잎은 「마무리 투수」 → 그림을 따름. ④ 그림 Ⅱ-9의 1(3할 이상)에 타율 0.29 무렵 점도 들어 있어 「0.300 이상」 정의와 맞지 않음 → 화면의 점은 0.300 기준으로 다시 표시. ⑤ 그림 Ⅱ-11·Ⅱ-12의 「다」 점(타율 약 0.26, 방어율 3.1)은 14번(0.250, 3.10)으로 봄. ⑥ 85쪽 주요 코드 `scaler = MinMaxScaler`에 괄호가 빠져 있고, 표의 `import ecisionTreeClassifier`는 오타 → 화면에는 바로잡아 싣고 그 사실을 적음. ⑦ 84쪽 지도 TIP은 펭귄 분류를 k-NN에 연결하지만 분류 알고리즘은 여럿이 가능 → 분류 게임 해설에 「교과서가 고른 답」과 그 근거(가까운 이웃의 다수결)를 함께 씀.

**검토 반영** — ① 분류 게임: 분류 문제는 여러 알고리즘이 가능하므로(부록 222쪽은 심장 마비에 k-NN·로지스틱 회귀·SVM·의사결정트리를 모두 듦) 안내에 「교과서 선 잇기처럼 알고리즘마다 문제 하나씩 짝지으며, 문장 속 단서(트리 구조, 발생/아님 두 가지, 가까운 이웃)로 골라요」를 넣음. 공용 `sorter`의 오답 문구(「정답은 ○○」)는 바꿀 수 없어서 같은 모양의 차시 전용 `alPick`을 lesson.js에 두고 오답 문구를 「교과서 짝은 ○○예요」로, 끝 문구를 「교과서 짝과 같게 골랐어요」로 바꿈. ② SVM 그림의 「다」(0.26, 3.10)는 경계에서 0.011로 서포트 벡터보다 가깝고 마진 안에 있어 「경계와 가장 가까이 맞닿은 점이 서포트 벡터」와 어긋남 → 회색 빈 점 「14번」으로 그리고, 범례·설명에 「포지션이 정해지지 않은 14번 — 학습에 쓰지 않은 점」이라고 적음(교과서 그림 Ⅱ-11은 타자처럼 그림 — 애매한 점 ⑤에 더함). ③ k-평균 「직접 놓기」 「새 선수 넣어 보기」에 (선택) 표시, 이름표 줄임말(중간·중 = 중간 투수, 마 = 마무리 투수, 선 = 선발 투수)을 안내 문구와 아래 설명에 적음. ④ 85쪽 코드 설명에 「교과서 코드는 X_scaled가 아니라 X를 train_test_split에 넣는다」 한 줄 추가(교과서 애매한 점 ⑧).
