예전에는 여행을 가려면 지도책을 펼치고 어떤 경로로 갈지 고민했어요. 초보 운전자가 지금 어느 도로를 달리는지, 어느 길로 빠져야 하는지 판단하기는 쉽지 않았지요. 내비게이션은 가고 싶은 장소만 입력하면 안내에 따라 목적지에 도착하게 해 줘요. 자율주행 자동차도 내비게이션 시스템으로 목적지까지의 경로를 찾아 주행해요.

01

목표에 어떻게 도달할 수 있을까?

교과서 29~30쪽 · 그래프와 트리, 탐색 트리, 4-queen

쉽게 말하면인공지능은 문제를 점(노드)과 선(링크)으로 나타내고, 시작 지점에서 출발해 목표 지점을 찾는 방법으로 문제를 해결해요. 이렇게 찾아가는 과정이 탐색이에요.

📖 그래프와 트리 (그림 Ⅰ-7)

인공지능에서 탐색은 모든 문제를 경우의 수로 표현하고 그래프(graph) 또는 트리(tree) 형태로 나타낼 수 있다. 그래프와 트리는 데이터를 나타내는 노드(node)와 데이터 간의 관계를 나타내는 링크(link)로 이루어져 있다.

🚇

그래프 · 예: 지하철 노선도

노드와 노드 사이에 순환(cycle) 구조를 가지는 경우가 있다. 한 역에서 출발해 다른 길로 다시 돌아올 수 있어요.

👪

트리 · 예: 가계도

트리는 그래프의 일종으로 계층 구조를 표현할 때 사용한다. 방향성이 있고 순환 구조를 가지지 않는다.

노드: 그래프나 트리에서 어떤 정보를 가진 데이터를 표현할 때 사용한다(수학에서는 정점). · 링크: 노드와 노드를 연결하는 선. 화살표 모양이면 방향성이 있는 것이다.

탐색 트리는 탐색할 노드들을 트리의 형태로 표현한 것이다. 탐색 트리에서는 모든 노드가 미리 생성된 것이 아니므로 현재 상태에서 상태가 변화할 때마다 새로운 상태가 나타나면서 트리를 생성한다.

♛ 4-queen: 퀸 4개를 서로 공격하지 않게 놓기 (그림 Ⅰ-8)

4×4 크기의 체스판 위에 4개의 퀸을 배치하는 게임이다. 퀸은 한 번 움직일 때 좌우, 상하, 대각선 방향으로 이동할 수 있다. 행이나 열에는 퀸이 한 개만 놓여야 하므로 1행부터 한 행에 하나씩 놓아 봐요. 초기 상태는 빈 체스판, 목표 상태는 퀸 4개가 서로 공격하지 않는 배치예요. 해답 하나를 찾으면 끝이에요.

4×4 체스판의 해답은 두 가지예요. 교과서(30쪽)는 그중 왼쪽 상태를 목표 상태로 정했지만, 여기서는 어느 해답을 찾아도 목표 상태로 인정해요.

이 게임을 풀기 시작하면 다양한 상태가 나올 수 있다. 이 상태를 모두 찾아내어 상태 공간을 그리면 목표 상태를 쉽게 파악할 수 있다. 더 해 보고 싶다면 스스로 해결하기(30쪽)처럼 8 Queens Problem 웹 사이트 ↗에서 5-queen 문제를 풀어 봐요.

02

맹목적 탐색은 무엇일까?

교과서 31~34쪽 · 탐색의 종류, 깊이 우선 탐색, 너비 우선 탐색

쉽게 말하면맹목적 탐색은 「어느 쪽이 목표에 가까울까?」 같은 정보 없이, 갈림길(분기점)에서 갈 순서를 미리 정해 두고 차례차례 살펴보는 방법이에요. 한 길로 깊게 먼저 가 보는 깊이 우선 탐색과, 같은 층을 넓게 먼저 보는 너비 우선 탐색이 있어요.

🗂️ 탐색의 종류 (그림 Ⅰ-9)

그래프 탐색에서는 출발 노드로부터 정해진 순서대로 노드를 확장하는 과정에서 목표 노드를 찾아낸다. 이때 탐색의 목적(어떤 경로든 신속하게 목표를 찾기 / 최적의 경로 찾기)과 탐색 과정에서 어떤 정보를 사용하였는가에 따라 다양한 선택이 이루어질 수 있다.

맹목적 탐색blind search · 무정보 탐색
깊이 우선 탐색 DFS: Depth First Search너비 우선 탐색 BFS: Breadth First Search
정보 이용 탐색informed search · 휴리스틱 탐색
언덕 등반 탐색 HCS최상 우선 탐색 Best First SearchA* 알고리즘

맹목적 탐색

무정보 탐색이라고도 하며 상태 공간에 관한 정보 없이 기계적인 순서로 모든 상태를 탐색하는 방법으로, 분기점에서 어떤 순서로 분기할지 미리 정해 두고 탐색한다.

정보 이용 탐색 (이어서 배워요)

휴리스틱 탐색 또는 경험적 탐색이라고도 하며 상태 공간에 관한 정보를 활용하여 지능적으로 그래프의 일부만 효과적으로 탐색함으로써 가까운 근삿값을 빨리 찾을 수 있다.

⬇️

깊이 우선 탐색 (DFS) · 32쪽

탐색 트리에서 갈 수 있는 길이 있는 한 앞으로 계속 전진하여 탐색하는 방법이다. 막다른 길에 다다르거나 길이 없는 경우에는 이전 상태 중 다른 경로로 갈 수 있는 분기점까지 되돌아가 다시 탐색한다. 분기점에서 어느 방향으로 갈지는 미리 정해 두어야 한다.

활용: 미로가 갈라질 때마다 한쪽을 선택해 깊숙이 들어가는 미로 탐색
➡️

너비 우선 탐색 (BFS) · 34쪽

탐색 트리를 넓고 얇게 탐색하는 방법이다. 분기점에 도착했을 때 분기점과 연결된 동일한 깊이의 상태 공간을 탐색한 후 다음 단계로 나아간다. 방문한 적이 있는 분기점은 재방문하지 않는다.

활용: 한 웹 페이지의 모든 링크를 확인한 뒤 다음 페이지로 가는 웹 크롤러

🔍 한 단계씩 따라가 보기 (그림 Ⅰ-10 · Ⅰ-12의 트리)

탐색 방법을 고르고 「한 단계」를 눌러 보세요. 분기점에서는 왼쪽 자식부터 가기로 정해 두었어요. 먼저 목표 K로 두 방법을 한 번씩 재생하고, 그다음 목표 노드를 하나만 바꿔 몇 번째에 찾는지 비교해 보세요.

💻 교과서 코드로 확인하기 (32·35쪽 스스로 해결하기)

교과서 QR 코드의 소스 파일은 그림 Ⅰ-10의 트리를 이렇게 딕셔너리로 나타내요. 각 노드에 연결된 노드를 적은 것이에요.

tree = {
    'A': ['B', 'C', 'D'],
    'B': ['A', 'E'],      'C': ['A', 'F'],      'D': ['A', 'G', 'H'],
    'E': ['B', 'I', 'J'], 'F': ['C'],           'G': ['D'],
    'H': ['D', 'K'],      'I': ['E'],           'J': ['E'],
    'K': ['H']
}
깊이 우선 탐색 — 방문하지 않은 노드를 만나면 그 노드에서 다시 같은 함수를 불러 더 깊이 들어가요. 
def DFS(graph, start, visited):
    visited[start] = True
    print(start, end=' ')
    for neighbor in graph[start]:
        if not visited[neighbor]:
            DFS(graph, neighbor, visited)
실행 결과 A B E I J C F D G H K
너비 우선 탐색 — 큐(queue)에 넣은 순서대로 앞에서 꺼내 방문하고, 자식 노드는 큐 뒤에 넣어요. 
from collections import deque
def BFS(graph, start):
    visited = {node: False for node in graph}
    queue = deque([start]); visited[start] = True
    while queue:
        node = queue.popleft()
        print(node, end=' ')
        for neighbor in graph[node]:
            if not visited[neighbor]:
                queue.append(neighbor); visited[neighbor] = True
실행 결과 A B C D E F G H I J K
03

강 건너기 문제

교과서 33·35쪽 · 깊이 우선 탐색 과정(그림 Ⅰ-11), 너비 우선 탐색 과정(그림 Ⅰ-13)

쉽게 말하면농부가 양, 늑대, 양배추를 배에 실어 손실 없이 강을 건너는 문제예요. 매 순간 누가 어느 쪽 둑에 있는지가 하나의 상태이고, 규칙을 어겨 무언가 잡아먹히는 상태는 금지 상태예요.

📜 규칙

① 농부는 강을 건널 때 양, 늑대, 양배추 중 한 가지만 배에 태울 수 있다.
② 양과 늑대만 남으면 늑대가 양을 잡아먹는다.
③ 양과 양배추만 남으면 양이 양배추를 먹는다.

✏️ 상태를 적는 방법

f 농부 · s 양 · w 늑대 · c 양배추. |(강)의 왼쪽이 서쪽 둑, 오른쪽이 동쪽 둑이에요. 처음에는 모두 서쪽 둑에 있으니 fcsw |, 목표 상태는 | fcsw예요.

🚣 직접 옮겨 보기

버튼을 눌러 농부가 무엇을 태우고 건널지 골라요. 금지 상태가 되면 경고가 뜨고, 되돌아가기로 이전 상태로 돌아가 다른 방법을 시도할 수 있어요. 한 번 움직일 때마다 아래 기록표에 한 줄씩 남아요. 막힌 기록도 지우지 않아요.

🌳 교과서 탐색 트리와 비교하기 (그림 Ⅰ-11 · Ⅰ-13)

번호는 각 상태에서 한 행동이에요. 깊이 우선 탐색은 분기점(6, 7)에서 왼쪽(6)부터 탐색해요. 순서를 재생해 보고, 내가 실제로 지나간 행동과 상태(파란 테두리·파란 선)와 비교해 보세요. 같은 상태가 두 곳에 있으면 내가 지나온 길 쪽만 표시돼요.

깊이 우선 탐색에서는 6번에서 8번으로 깊게 내려가지만, 너비 우선 탐색에서는 6번에서 7번으로 같은 레벨 노드끼리 탐색하고 다음 레벨에서 또 같은 레벨 노드끼리 탐색한다. 깊게 내려가는 것이 아니라 같은 레벨을 탐색한 후 다음 레벨로 이동하므로 천천히 깊어진다.
04

스스로 해결하기 · 5L와 3L 물통으로 4L 만들기

교과서 34쪽 · 탐색 트리로 만들고 깊이 우선·너비 우선 탐색으로 탐색하기

쉽게 말하면눈금 없는 5L와 3L의 빈 물통 2개로 4L의 물을 만들어요. 할 수 있는 일은 가득 채우기 · 비우기 · 다른 물통에 붓기뿐이에요. 두 물통에 든 물의 양을 (5L 물통, 3L 물통)으로 적으면 그것이 하나의 상태예요. 처음은 (0, 0)이에요.

🪣 직접 부어 보기

지금 상태에서 할 수 있는 행동만 버튼이 켜져요. 처음 나온 상태는 아래 탐색 트리에 새 노드로 붙고, 이미 나온 상태로 돌아오면 새로 붙지 않아요. 트리의 노드를 누르면 그 상태로 되돌아가 다른 행동을 해 볼 수 있어요. 5L 물통에 4L가 생기면 성공!

📈 선생님과 함께 · 확인할 상태는 몇 개일까?

맹목적 탐색은 목표가 어디쯤인지 모른 채 정해진 순서대로 살펴봐요. 분기점마다 갈 수 있는 길의 수와 목표까지의 깊이를 바꿔 보며, 최악의 경우 확인해야 할 상태 수를 계산해 보세요.

🧭 그래서 정보 이용 탐색이 필요해요

맹목적 탐색은 방문한 상태를 다시 가지 않고 모든 상태를 차례로 보면 답을 찾을 수 있지만, 아무런 정보 없이 탐색해요. 그리고 깊이 우선 탐색은 해답이 없는 깊은 경로를 탐색하는 경우에는 빠져나오지 못할 수 있어요(33쪽). 정보 이용 탐색은 비슷한 문제에 대한 이전 경험이나 지식을 바탕으로 어떤 기준을 판단하여 결정하는 탐색 방법으로, 탐색 시간을 줄일 수 있어 많이 사용된다(36쪽). 정보 이용 탐색이 항상 옳은 것은 아니지만 대부분의 경우에 잘 맞는 정보를 제공한다(31쪽).

오늘 배운 것 정리 · 질문폼

탐색은 문제를 노드와 링크로 이루어진 그래프나 트리로 나타내고, 초기 상태에서 출발해 목표 상태를 찾는 과정이다. 탐색 트리는 상태가 변할 때마다 새로운 상태가 나타나며 자란다.
맹목적 탐색은 상태 공간에 관한 정보 없이 정해진 순서대로 탐색한다. 깊이 우선 탐색은 깊게 먼저 가고 막히면 되돌아가며, 너비 우선 탐색은 같은 깊이를 모두 본 뒤 다음 단계로 간다.
답이 있으면 찾을 수 있지만 상태가 많아지면 살펴볼 것이 급격히 늘어난다. 그래서 상태 공간에 관한 정보를 활용하는 정보 이용 탐색이 필요하다.

질문폼에 내 생각 쓰기

  1. '강 건너기' 문제(농부·양·늑대·양배추)를 직접 옮겨 보며 풀었습니다. 풀 때 한 가지 방법을 끝까지 해 보고 막히면 되돌아왔나요, 아니면 여러 경우를 조금씩 번갈아 시도했나요? 자신이 실제로 한 방식을 쓰고, 막다른 상황에서 어떻게 다시 시도했는지 설명하세요.
  2. 5L와 3L 물통으로 4L를 만드는 문제를 직접 풀어 보았습니다. 푸는 동안 매 순간 '두 물통에 물이 얼마나 들어 있는지'가 달라졌을 텐데, 한 단계와 다음 단계를 서로 다른 상황으로 구분한 기준은 무엇이었나요? 그리고 그 상황에서 다음에 할 수 있는 행동은 어떻게 정해졌는지 쓰세요.
  3. 맹목적 탐색은 정보 없이 모든 상태를 규칙대로 살펴봅니다. 방문한 상태를 다시 가지 않고 모든 상태를 차례로 살펴보면 답을 찾을 수 있다는 장점이 있는데도 실제 문제에서 잘 쓰이지 않는 이유는 무엇일지 자신의 생각을 쓰세요.
