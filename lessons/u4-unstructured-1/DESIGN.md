## 교과서 오류·모호한 곳과 처리
1. **209쪽 summary 결과가 코드와 다름** — 코드는 세 번째 합성곱층이 `Conv2D(32, …)`인데 실행 결과 그림은 `(None, 96, 96, 64)`·Param 18496, Flatten 147,456, Total 18,898,209 → 필터 64개로 실행한 결과. 교과서 소스 노트북(코드와 같음)의 출력은 (96, 96, 32)·9,248, Flatten **73,728**, Total **9,451,777**(직접 계산으로도 확인: 448 + 4,640 + 9,248 + 9,437,312 + 129). 화면 03은 노트북 값으로 쓰고, 층 모양 체험의 「마지막 합성곱 필터 64」 단추로 교과서 숫자가 어디서 나왔는지 보여 줌.
2. **209쪽 해석 「한 개의 이미지에서 총 … 매개 변수가 생성」** — 매개 변수는 이미지마다 생기는 것이 아니라 모델이 학습하는 가중치·편향의 수 → 화면에서 「모델 전체가 학습하는 매개 변수의 수」로 풀어 씀.
3. **208쪽 컨볼루션 출력 그림** — 같은 입력·커널로 계산하면 [[2, 3, 2], [2, 4, 3], [2, 2, 2]]인데 그림은 [[2, 4, 2], [3, 4, 3], [2, 2, 2]](첫째 줄 가운데 4 → 3, 둘째 줄 왼쪽 3 → 2). 계산 방법 예시(왼쪽 위 = 2)는 맞음. 화면은 계산값으로 그리고 「교과서 그림에는 두 칸이 4·3으로 실려 있어요」 한 줄. 풀링 예시(최대 100·184·12·45, 평균 36.5→그림 36, 80, 12, 15)는 맞음(평균 36.5를 그림은 36으로 표기 → 화면에 36.5).
4. **205쪽 `read_img` 주석 「이미지를 흑백으로 변환한 결과 반환」** — 실제로는 BGR → RGB(컬러) 변환. 본문(「BGR 형식에서 RGB 형식으로 변환」)이 맞음 → 노트북 주석과 화면을 본문대로.
5. **212~213쪽 새 이미지 정규화 빠짐** — 학습은 `rescale = 1/255`로 0~1 값을 썼는데 새 이미지는 0~255 그대로 `predict`에 넣음. 값이 255배 커서 출력이 `[0.]`·`[1.]`처럼 끝까지 쏠려 나오고, 그래서 `if classes1[0]==0:`이 우연히 맞게 동작함. 정규화하면 출력이 0.03처럼 0과 1 사이 확률로 나오고 `classes1[0]==0` 비교로는 늘 「Non Fire Image」가 됨(지도 TIP도 「0 또는 1로 나오지 않을 경우 임계값 설정」을 언급). → 노트북·화면 모두 `/ 255`를 더하고 `classes1[0][0] < 0.5`로 판정, 「더한 부분」으로 표시하고 이유를 화면 05에 설명.
6. **210쪽 batch_size 9 = 324의 약수, steps_per_epoch 36** — 데이터가 324장일 때 맞음(zip도 324장 그대로라 같음).
7. 211쪽 학습 기록 숫자(61s·0.6944 …)와 교과서 소스 노트북 기록(0.6019 … 0.9753)이 다름 — 학습할 때마다 달라지는 값. 셀 흉내는 소스 노트북 기록 8줄 전체를 씀(교과서는 4~6번째 줄 생략).
8. 206쪽 `train_fire[7]`은 `glob` 순서가 컴퓨터마다 달라 학생마다 다른 사진이 나옴 → 화면에 한 줄.
9. 데이터 자체: **non 폴더의 non_fire.133은 산불 사진**(불꽃·연기), non_fire.20도 공장 굴뚝 연기. 교과서 데이터 그대로 두고 화면 02 「더 알아보기 · 시각화로 데이터 문제 찾기」로만 알림(206쪽 지도 TIP 「데이터에 문제가 있는지 확인」과 연결). fire 폴더에는 건물 화재·소방관 사진이 많음(산불만은 아님) → u4-unstructured-2의 편향 이야기로 이어짐.
10. 최신 코랩(케라스 3)에서 `input_shape=`를 층에 넣으면 경고(UserWarning)가 한 줄 나올 수 있음 — 오류가 아니라 그대로 진행. 화면 03 셀 흉내 아래 한 줄.

## 체험 위젯
1. **사진은 숫자 (400, 400, 3)** (02, `#pxGame`): 캔버스(200×200 썸네일, 400×400 사진의 한 점 = 2×2 픽셀로 안내)를 누르거나 방향키로 십자선을 옮기면 그 점의 R·G·B 막대와 숫자, ÷255 값. 「cv2로 읽은 그대로(BGR) 보기」 단추는 R과 B를 바꿔 다시 그림 → 불꽃이 파랗게. 산불/숲 사진 바꾸기. 캔버스가 막히면(file:// 등) 안내 문구. 방향키는 `preventDefault`.
2. **합성곱 출력 칸 계산** (03, `#convGame`): 출력 3×3 칸을 누르면 입력의 3×3 창이 칠해지고 곱셈 9개와 합이 나옴. 버튼이라 터치·Enter 모두 됨.
