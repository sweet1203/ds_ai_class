기계학습으로 어떤 문제를 해결할 수 있을까?

교과서 59쪽 · 전통적 프로그래밍과 기계학습, 서울의 평균 기온 데이터

쉽게 말하면전통적 프로그래밍은 사람이 규칙을 정해 주면 컴퓨터가 그대로 계산해요. 기계학습은 기계가 데이터를 보고 스스로 규칙과 패턴을 찾은 뒤, 그 규칙으로 새로운 데이터에 대해 예측해요.

기계학습

과거에 구매한 것과 유사한 특징의 다른 물건을 추천하거나, 나와 같은 물건을 구매한 다른 사람의 취향을 반영하여 새로운 물건을 추천하는 것

물건의 속성들과 나의 선택, 나와 같은 선택을 한 다른 사람이 선택하는 물건의 특징에 해당하는 데이터를 학습시켜 기계가 스스로 규칙과 패턴을 찾고, 그 규칙에 따라 나에게 새로운 추천을 한다.

기계학습은 데이터를 학습시켜 스스로 규칙을 발견하고, 이를 새로운 데이터에 적용하여 정보를 얻거나 예측하는 기술을 말한다.

전통적 프로그래밍 적용

(가) 평균 기온이 가장 높은 해는 언제일까?

평균 기온 속성의 데이터를 모두 비교하여 가장 큰 값을 찾은 후 해당하는 연도를 출력한다.

기계학습 적용

(나) 2050년의 평균 기온은 얼마나 될까?

주어진 데이터에 답을 찾기 어렵거나 사람이 규칙을 발견하기 어려운 문제는 기계가 스스로 데이터를 학습하여 규칙을 발견한 후 이를 활용하여 해답을 찾는다.

이처럼 기계학습으로 해결할 수 있는 문제는 관련 데이터 안에서 답을 찾기 어렵거나 사람이 명확한 규칙을 찾기 어려워 기계가 스스로 학습하여 결과를 예측하는 것으로 볼 수 있다.

🧩 규칙은 어디에 있을까? (59쪽 그림)

두 방법은 무엇을 넣고 무엇을 얻는지가 달라요. 빈칸을 눌러 데이터 · 규칙 · 결괏값 중 하나를 넣고(누를 때마다 바뀌어요), 다 채우면 「확인하기」를 눌러 보세요. 위 (가)·(나)를 떠올리면 쉬워요.

붓꽃 데이터

이미지 검색뿐 아니라 꽃의 속성 데이터를 활용한 기계학습으로 꽃을 분류할 수 있다. 영국의 통계학자이자 생물학자인 로널드 피셔가 1936년에 정리한 150개의 붓꽃 데이터는 다양한 문제 해결에 활용되고 있다.

붓꽃의 속성: 꽃잎 길이, 꽃잎 너비, 꽃받침 길이, 꽃받침 너비 (그리고 종류)

문제를 고르면 붓꽃 표에서 알고 있는 것(초록)과 알아내려는 것(?)이 표시돼요. 표를 보고 유형을 골라 본 다음, 「기계에게 맡겨 보기」로 결과를 확인하세요. 붓꽃 150송이는 교과서 붓꽃 데이터 그대로이고, 「새로운 꽃」의 값은 예시예요. 답은 아래 「풀고 나서 확인」에 있어요.

(다)에서는 꽃잎 너비를 모르는 값으로 정했어요. 교과서 표 Ⅱ-3은 꽃받침 너비를 예로 들어요. 어느 속성이든 모르는 수치를 구하면 회귀 문제예요.

마무리

오늘 배운 것 정리 · 질문폼

기계학습은 데이터를 학습시켜 스스로 규칙을 발견하고, 새로운 데이터에 적용하여 정보를 얻거나 예측하는 기술이다. 데이터 안에서 답을 찾기 어렵거나 사람이 명확한 규칙을 찾기 어려운 문제에 알맞다.
기계학습을 적용한 문제 해결은 문제 정의 → 데이터 수집 → 데이터 전처리 → 기계학습 유형과 알고리즘 선정 → 모델 학습 → 성능 평가 및 수정 과정을 거치고, 성능을 높이려고 이전 단계로 돌아갈 수 있다.
같은 붓꽃 데이터라도 문제를 어떻게 정의하느냐에 따라 군집 · 분류 · 회귀로 달라지고 필요한 속성도 달라진다. 그래서 문제 정의가 매우 중요하다.
