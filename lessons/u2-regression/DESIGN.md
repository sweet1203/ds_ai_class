**50분 흐름** — 도입(3분) (다) 문제 → 01(9분) 직선 맞추기로 MSE·R² 감 잡기 → **02(15분)** 코랩 노트북을 위에서부터 실행해 오류를 직접 만나고 원-핫 인코딩으로 해결, 끝까지 실행(예측까지). 못 여는 학생은 셀 흉내로 → 메모 2칸 → 03(10분) 노트북 결과 숫자를 화면과 맞춰 보고, 채점 비교, 메모 → 04(6분) 계산기로 4.867 확인 → 마무리(7분) 질문폼.

**노트북** — `assets/iris-linear-regression.ipynb` + `assets/Iris1.csv`(교과서 86쪽 폴더의 Iris1.csv 그대로, cp949). 교과서 원본 노트북(67~72쪽 전처리 + 86쪽)에서 86~87쪽 부분만 골라 셀을 다시 짰음: 파일 업로드 대신 GitHub 원본 주소에서 `read_csv`, ① X·y·분할 → ② 학습(**오류 셀**) → 해석 → ③ get_dummies → 「다시 나누고 학습」 셀 → ④ 가중치·편향 → R² → MSE(더한 셀) → 예측. 원본 노트북에는 오류가 나는 학습 셀이 없었으므로(① 다음 바로 get_dummies) 교과서 86쪽 순서대로 넣음. 로컬(pandas 3.0, scikit-learn 1.9)에서 셀을 차례로 실행해 확인: ② 셀 `ValueError: could not convert string to float: '버지니카'`(교과서와 같은 문구), 가중치 [0.5851811 0.78889363 -0.31301472 -0.07307218 -0.36541193 0.43848411], 편향 1.4937, R² 0.7854, MSE 0.1156, 예측 [4.86696366]. 화면에 실은 출력은 이 값.

**계산 확인** — 01 산점도: Iris1.csv 150개, 꽃잎 길이 → 꽃받침 길이 최소제곱 직선 y = 0.4091x + 4.3056, MSE 0.1635, R² 0.7600, 평균선(y = 5.843) MSE 0.6811 = 분산, R² 0. 03의 5개: 일련번호 150·85·41·42·53(random_state = 7 테스트 데이터 30개 중 1·2·3·6·7번째), 실젯값 5.9·5.4·5.0·4.5·6.9, 예측값 6.344·6.257·4.912·4.210·6.631 → MSE 약 0.219, R² 약 0.675, 똑같이 맞힌 것 0개(30개 전체로도 0개). 04 계산기: 0.5851811×3.1 + 0.78889363×1.5 − 0.31301472×0.2 + 0.43848411×1 + 1.49368065 = 4.86696.

**교과서에서 애매한 점** — ① 87쪽 2 성능 평가의 실행 결과가 「결정 계수 R2: 1.0」으로 실려 있으나 같은 코드·데이터로 실행하면 0.785(교과서 원본 노트북 출력도 0.7854) → 화면은 0.785를 싣고 「교과서에는 1.0으로 실려 있지만」이라고 밝힘. ② 87쪽 가중치 출력이 [[ … ]], 편향이 [1.49368065]로 2차원처럼 실려 있으나 실제 출력은 1차원 → 실제 출력을 실음. ③ 「3 코드 실행 후 1, 2 코드를 다시 실행하세요」: ①의 X 줄은 이미 사라진 '종류' 열을 찾으므로 그대로 다시 실행하면 KeyError → 노트북에는 나누기·학습만 다시 적은 셀을 두고 화면에서도 그렇게 안내. ④ 최신 판다스는 get_dummies 결과를 True/False로 보여 주므로 노트북·화면 코드에 `dtype = int`를 더하고 그 사실을 적음. ⑤ 87쪽 본문은 MSE와 R²를 함께 소개하지만 코드는 R²만 계산 → 노트북에 MSE 셀을 「교과서 코드에 더한 셀」로 넣음. ⑥ 87쪽 그림 Ⅱ-13(회귀선 예시)의 축 이름이 「집값」「방의 개수」로 붓꽃과 다른 예 → 화면에서는 붓꽃 산점도로 대신함. ⑦ 87쪽 지도 TIP의 가중치·편향·오차 정의는 학생용 본문에 없어 「더 알아보기」로만 씀. ⑧ 질문폼 3번의 「앞서 분류 문제에서 쓴 정확도」는 78쪽 k-최근접 이웃 붓꽃 분류(테스트 데이터 정확도 0.967) → 03에서 그 값을 다시 보여 줌.
