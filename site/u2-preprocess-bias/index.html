데이터 편향성은 무엇일까?

교과서 64쪽 · 데이터 편향성, 데이터 편향성이 발생하는 원인

쉽게 말하면데이터가 현실 세계를 골고루 담지 못하고 한쪽으로 치우친 것이 데이터 편향성이에요. 데이터를 모을 때, 다듬을 때, 그리고 어떤 속성을 고를 때 모두 치우침이 끼어들 수 있어요.

📖 데이터 편향성

기계학습은 학습에 사용되는 데이터의 질과 양에 의해 성능이 결정된다. 특히 데이터의 편향성(data bias)은 인공지능이 만들어 내는 결과의 신뢰 여부를 결정하는 중요한 요소이다.

데이터 편향성이란 데이터가 현실 세계를 잘 반영할 수 있을 만큼 충분히 확보되지 않아 실제 세계를 표현하지 못하거나 한쪽으로 치우친 경향을 보이고 있는 것을 말한다.

🔎 데이터 편향성이 발생하는 원인

기계학습을 적용한 문제 해결 과정에서 다양한 편향이 발생할 수 있다.

🧺

🧹

데이터 전처리

데이터를 수집하여 입력할 때 잘못 입력하거나 비어 있는 값을 채워 넣는 과정에서 발생

🏷️

편향은 무엇을 망칠까?

교과서 64쪽 · 편향된 데이터로 학습했을 때의 결과, 정확성과 공정성

쉽게 말하면치우친 데이터로 공부한 인공지능은 틀리는 일이 많아지고(정확성), 그 틀림이 특정한 사람들에게 몰리기 쉬워요(공정성). 그래서 데이터를 모으는 단계부터 조심해야 해요.

📖 교과서 문장

이러한 다양한 원인에 의한 편향이 반영된 데이터로 기계학습이 진행되면 결과의 정확성이 떨어지고 공정성을 갖기 힘들다. 따라서 데이터 수집 단계에서부터 공정하고 정확한 데이터 수집을 위해 노력해야 한다.

🔊 AI 스피커 시뮬레이션 (예시)

어느 AI 스피커가 목소리 데이터로 말을 알아듣는 법을 학습해요. 실제 사용자는 청소년 70%, 어르신 30%라고 해 볼게요. 학습 데이터에 어르신 목소리를 얼마나 넣을지 바꿔 보며 두 막대를 비교하세요. 숫자는 설명을 위해 만든 예시예요(실제 측정값이 아니에요).

🤔 생각해 보기 · 「정확하지 않다」와 「공정하지 않다」

🎯 정확성

인공지능의 결과가 얼마나 맞는가. 전체 정확도가 낮으면 누구에게나 틀린 답을 자주 내요.

⚖️ 공정성

결과가 집단에 따라 고르게 나오는가. 전체 정확도가 높아도 틀리는 일이 한 집단에 몰리면 그 사람들은 불리해져요.

데이터 속성을 어떻게 구분할까? 선생님과 함께 빠르게

교과서 66쪽 · 속성명과 속성값, 수치형과 범주형, 독립 변수와 종속 변수

쉽게 말하면표의 열 이름이 속성명, 칸에 든 값이 속성값이에요. 속성값은 숫자로 계산할 수 있는지(수치형), 몇 가지 갈래 중 하나인지(범주형)로 나누고, 기계학습에서 무엇을 맞히려는지에 따라 독립 변수와 종속 변수로 나눠요.

📖 속성명과 속성값 (그림 Ⅱ-2)

사람은 감각 기관과 경험을 통해 세상을 이해하지만 기계는 입력된 데이터로 세상에 대한 지식을 갖게 된다. 기계는 성별, 나이, 키, 학교, 취미 등의 속성으로 이루어진 데이터를 입력받아 사람에 대해 학습한다. 이때 데이터 속성은 속성명과 속성값으로 구분된다.

데이터 편향성은 데이터가 현실 세계를 잘 반영하지 못하거나 한쪽으로 치우친 것이다. 데이터 수집(특정 집단이 너무 많거나 적거나 누락), 데이터 전처리(잘못 입력, 빈 값 채워 넣기), 속성 선택(무의식적인 사회의 편향) 단계에서 생길 수 있다.
편향이 반영된 데이터로 학습하면 결과의 정확성이 떨어지고 공정성을 갖기 힘들다. 그래서 데이터 수집 단계에서부터 공정하고 정확한 데이터를 모으려고 노력해야 한다.
데이터 속성은 유형에 따라 수치형·범주형, 역할에 따라 독립 변수·종속 변수로 구분한다. 데이터 전처리(정제·통합·축소·변환)의 하나로 pd.concat()을 써서 두 데이터를 통합했다.
