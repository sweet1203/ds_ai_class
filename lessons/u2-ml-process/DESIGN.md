쓰기 메모 4칸(`recoWhy`·`myProblem`·`tradML`·`myWords`) + 고르기 1개(`slowStep`) + 칩 1개. 퀴즈 11문항. 질문폼 1번 ← 01 규칙 퍼즐·04 판별표·`tradML`·`myProblem`, 2번 ← `myWords`(04에서 개념 빈칸 뒤), 3번 ← 0 추천 이야기·03 `myProblem`.

**50분 흐름** — 도입(5분) 단원 지도·짧은 이야기는 훑고, 추천 이야기와 학습 계획 ② → 01(9분) 추천 예시·(가)(나) 대조, 규칙 퍼즐 → 02(9분) 6단계 순서 맞추기, 단계별 한 줄씩 읽기, 시간 많이 걸릴 단계 고르기 → **03(23분 무렵 시작, 11분)** (가)(나)(다)를 차례로 풀고 기계에게 맡겨 보기, `myProblem` → 04(8분) 판별표·발표, 메모 두 칸, 빈칸 → 마무리(8분) 퀴즈 결과 확인 후 질문폼.

**줄인 것** — 54~57쪽 대단원 도입은 시작 화면의 작은 카드 두 개(배울 내용, 짧은 이야기 네 줄)로만. 55쪽 성취수준·지도 계획은 넣지 않음. 03의 묶기·가까운 이웃·직선 계산 방법은 설명하지 않고 결과만 보여 줌(74쪽 이후에 배움). 결측치·이상치·스케일링·인코딩 낱말 뜻은 02에 한 줄로만(60쪽).

**확인할 점(교과서 모호한 부분)**
- 학생용 교과서 확인 결과(검토): 59쪽 전통적 프로그래밍/기계학습 그림, 60쪽 「전처리에 가장 많은 시간」 Tip과 결측치·이상치·스케일링·인코딩 낱말 풀이는 학생 교과서에도 있음 → 쪽수를 달아 인용. 59쪽 「점검 포인트」와 61쪽 예시 답안은 교사용이라 「예시 답안」으로만 씀.
- 59쪽 점검 포인트 예시 답 「기계학습을 위해서는 데이터와 결괏값(정답)이 필요」는 61쪽 (가) 군집(정답 없이 구분)과 맞지 않음 → 01 퍼즐 뒤에 「정답 없이 학습하는 경우도 있어요(03에서)」를 덧붙임.
- 60쪽은 6단계(데이터 수집과 전처리, 모델 학습과 성능 평가가 따로), 61쪽 주요 개념 정리는 「데이터 수집 및 전처리」「모델 학습 및 성능 평가」로 묶어 씀 → 화면은 60쪽 6단계를 기본으로 하고 빈칸은 61쪽 문장 그대로.
- 60쪽 「기계학습 유형과 알고리즘 선정」은 회귀/분류만 예로 들고, 61쪽은 군집까지 셋 → 퀴즈는 교과서 문장 그대로만 씀.
- 61쪽 스스로 해결하기 이유(약 추천 = 분류, 물류 센터 추가 = 군집, 최다 유통 = 최댓값)는 교사용 예시 답안 → 「더 알아보기 · 선생님용 예시 답안」으로 보여 줌. 「진단한 환자에게 필요한 약」은 학생에 따라 전통적 프로그래밍(처방 규칙)으로 볼 수도 있어 발표 때 이유를 들어 보게 함.
- 03 (다)는 꽃잎 너비를 모르는 값으로 삼았지만 교과서 표 Ⅱ-3(그리고 u2-preprocess-bias)은 꽃받침 너비를 예로 듦 → 화면에 「교과서 표 Ⅱ-3은 꽃받침 너비를 예로 들어요」 한 줄을 넣음(산점도가 꽃잎 길이·너비라 계산은 그대로 둠).
- 03의 새로운 꽃 측정값(꽃받침 6.0·2.9, 꽃잎 4.5·1.5 / 버지니카 꽃잎 길이 5.5)은 예시. 붓꽃 150개 값은 교과서 65쪽 Iris1.csv 그대로.
- 58쪽 학습 계획 ①의 예시 답(시청·검색 기록 바탕 맞춤 추천)은 교사용 → 화면에 넣지 않음.
