모델 학습

교과서 198쪽 · 모델 생성하기, 모델 학습하기, 가중치와 편향 확인하기

쉽게 말하면선형 회귀 모델은 속성 20개에 각각 가중치를 곱해 더하고 편향을 더해 기대 수명을 계산해요. fit()은 훈련 데이터를 보고 오차가 가장 작아지는 가중치와 편향을 찾는 과정이에요.

🧾 가중치를 속성 이름과 나란히 보기 (노트북에 더한 셀)

학습한 모델의 식: 예측 기대 수명 = w1 × Year + w2 × Status + … + w20 × Schooling + b. 「부호」 칸의 배지는 가중치가 +(빨강)인지 −(파랑)인지를 나타내요.

🔎 더 알아보기 · 가중치가 클수록 중요한 속성일까?

꼭 그렇지는 않아요. 가중치는 속성값이 1 늘 때 예측이 얼마나 바뀌는지를 나타내므로, 속성값의 단위에 따라 크기가 달라져요. 소득(Income composition, 자원 소득에 대한 국가 개발 정도)은 0~1 사이 값이라 가중치가 11.3처럼 커 보이고, 인구수(Population)는 수억 명까지 커지는 값이라 가중치가 0.0000000007처럼 아주 작아요.

그래서 가중치의 크기만 보고 「어떤 속성이 더 중요하다」고 말하기는 어려워요. 모든 속성을 평균 0, 표준편차 1로 맞추는 표준화를 한 뒤 학습하면 가중치끼리 비교하기 쉬워져요(04 화면 더 알아보기).

🛠 더 알아보기 · 결정 계수가 0.79가 아니라 0.56쯤 나온다면?

교과서 소스 코드 노트북을 집 컴퓨터나 새 버전(1.9 이상)의 사이킷런(scikit-learn)에서 실행하면 가중치가 위와 전혀 다르고 결정 계수가 약 0.5577로 나올 수 있어요. 새 버전의 LinearRegression은 크기가 아주 다른 속성(인구수는 수억, 소득은 0~1)이 섞인 데이터에서 아주 작은 값을 버리고 계산하기 때문이에요.

이 수업의 노트북은 모델 생성 셀 다음에 「버전 맞춤」 셀(if 'tol' in linear_reg.get_params(): linear_reg.set_params(tol = 0))을 두어 어느 버전에서나 교과서와 같은 결과가 나오게 했어요. 버전이 낮으면 이 줄은 아무 일도 하지 않아요.

03

성능 평가

교과서 199쪽 · 결정 계수 확인하기, 테스트 데이터로 평가하기

쉽게 말하면모델이 처음 보는 테스트 데이터 330개로 시험을 봐요. 결정 계수(R²)는 1에 가까울수록 성능이 높고, 실제 기대 수명과 예측 기대 수명의 차이(오차)를 보면 몇 년쯤 빗나가는지 알 수 있어요.

1 결정 계수 확인하기

from sklearn.metrics import r2_score
y_pred = lin_results.predict(X_test)        # 테스트 데이터의 예측 기대 수명
print('결정 계수(R^2) = ', r2_score(y_test, y_pred))
결정 계수(R^2) =  0.7935432521020239

r2_score(y_test, y_pred)는 회귀 모델의 결정 계수를 계산하는 함수예요. y_test는 테스트 데이터의 실제 종속 변숫값, y_pred는 모델이 예측한 값이에요. R²가 1에 가까울수록 성능이 높고, 0에 가까울수록 낮아요.

R²(결정 계수) 독립 변수가 종속 변수를 얼마만큼 설명해 주는지를 나타내는 비율로, 1에 가까울수록 성능이 우수하다(87쪽). → 0.79는 20개 속성으로 기대 수명이 나라마다 다른 정도의 약 79%를 설명한다는 뜻이에요.

수정 및 성능 개선

교과서 200쪽 · 선형 회귀 알고리즘으로 회귀선과 모델의 성능 확인하기

쉽게 말하면속성 하나(교육 기간)로만 학습해 회귀선을 그려 보면 모델이 데이터의 경향을 어떻게 배웠는지 눈으로 볼 수 있어요. 어떤 속성을 쓰느냐에 따라 성능이 달라지므로, 속성을 바꿔 보는 것도 성능 개선 방법이에요.

1~4 교육 기간(Schooling)으로 회귀선 그리기

lin1 = LinearRegression()                                     # 1 선형 회귀 알고리즘 불러오기
lin1.fit(X_train['Schooling'].values.reshape(-1, 1),          # 2 교육 기간 하나로 학습하기
         y_train.values.reshape(-1, 1))
x_array = np.arange(min(X_train['Schooling']),                # 3 최솟값부터 최댓값까지 만들고
                    max(X_train['Schooling'])).reshape(-1, 1)
y_head = lin1.predict(x_array)                                #   예측값 생성하기
plt.scatter(X_train['Schooling'], y_train)                    # 4 산점도와
plt.plot(x_array, y_head, color = 'red')                      #   빨간 회귀선
plt.xlabel('Schooling'); plt.ylabel('Life expectancy'); plt.show()

reshape(-1, 1)은 배열을 2D로 바꿔요. 열의 수는 1로 고정하고 행의 수는 자동으로 정하라는 뜻이에요. 교과서의 축 이름 'Scooling', 'Life excpectancy'는 오타라서 바로잡았어요.

해석 교육 수준이 증가함에 따라 기대 수명이 증가하는 회귀선을 확인할 수 있다.

📈 회귀선 탐색기 · 속성을 바꿔 다시 학습하기

위: 속성 하나를 고르면 훈련 데이터 1,319개의 산점도와 그 속성으로 학습한 회귀선이 나와요. 아래: 속성을 여러 개 골라 함께 학습하면 테스트 데이터 결정 계수가 어떻게 되는지 비교해요.

🧹 데이터를 바꿔 성능 높이기 · 앞 단계의 결측치 처리 실험실과 이어 보기

속성만 고르면 결정 계수가 20개 전체(0.794)를 넘지 못했어요. 이번에는 데이터를 바꿔 봐요. 결측치가 많은 속성을 먼저 지우고 dropna()를 하면 남는 행이 늘어나요. 같은 코드(8 : 2, random_state = 96)로 다시 학습한 결과예요. (노트북의 마지막 「더 알아보기」 셀에서 직접 바꿔 볼 수 있어요.)

인구수는 기대 수명과 관계가 거의 없는 속성(상관계수 −0.02)이라, 지워도 손해가 적고 데이터는 늘어요. 다만 지울 때마다 테스트 데이터도 달라지므로 결정 계수를 똑같은 시험으로 비교한 것은 아니에요. 그래도 「데이터를 어떻게 준비하느냐」가 성능을 바꾼다는 것은 확인할 수 있어요.

🔎 더 알아보기 · 표준화를 하면 성능이 오를까?

표준화는 모든 속성을 평균 0, 표준편차 1로 맞추는 전처리예요(펭귄 분류 프로젝트에서 성능 개선에 썼어요). 이 데이터를 표준화한 뒤 선형 회귀로 학습해도 결정 계수는 0.794로 같아요. 선형 회귀는 속성값에 곱하는 가중치가 단위에 맞춰 바뀔 뿐이라 예측값이 그대로이기 때문이에요.

대신 표준화하면 가중치끼리 크기를 비교하기 쉬워지고, 크기가 아주 다른 속성 때문에 생기던 사이킷런 버전 문제도 사라져요.

선형 회귀 분석 결과를 해석할 때 독립 변수(x)의 크기가 예측의 정확도에 영향을 미칠 수 있어요. 만약 x값이 이상치처럼 아주 커지면, 예측이 정확하지 않을 수 있어요. (GDP 산점도의 오른쪽 끝 점들을 살펴보세요.)
