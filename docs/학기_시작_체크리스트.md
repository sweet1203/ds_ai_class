# 학기 시작 체크리스트

## 0. 다음 학기 처음 한 번: 새 수집 방식으로 바꾸기 (2026-11-22 준비)

2026-2학기에는 수집기를 둘 썼습니다. 진도는 이 저장소의 진도 수집기, 질문폼은 `질문폼_HTML/apps_script`(인C·인F·인G 반 시트 전용)로 받았습니다.
다른 네 과목(정보·데이터 과학·소프트웨어와 생활·프로그래밍)처럼 **진도 시트 하나가 질문폼도 받도록** 바꿉니다. 코드는 이미 들어 있고(`apps_script/Code.gs`), 학기가 끝난 뒤 아래만 하면 됩니다.

1. 진도 수집 시트 → 확장 프로그램 → Apps Script를 엽니다.
   - `apps_script/Code.gs`를 통째로 붙여넣고 저장합니다.
   - 맨 위 `var 반목록 = [...]`은 `[]`로 비웁니다. 반은 「명단」에서 찾습니다.
   - **배포 관리 → 연필 → 버전 「새 버전」 → 배포**를 누릅니다. 「새 배포」는 누르지 않습니다. 주소가 그대로여야 합니다.
2. `forms/forms.json`
   - `endpoint`를 `course.json`의 `progressEndpoint`와 **같은 주소**로 바꿉니다.
   - `classes`는 `[]`로 비웁니다. 그러면 질문폼에 반 칸이 없어지고 수집기가 명단에서 반을 찾습니다.
3. `course.json`의 `classes`도 `[]`로 비웁니다. 반 고르기 대신 명단 확인만 쓰게 됩니다.
4. 시트 메뉴에 「질문폼 제출 현황 정리」가 생깁니다. 질문 답은 「질문응답」 탭, 현황은 「질문현황」 탭에 쌓입니다.
5. 예전 질문폼 수집 시트(인C·인F·인G)는 보관용으로 두고 더 쓰지 않습니다.

> 내용 정리 거리(새 과목 점검 기준): 정보 과목의 `tools/check.py`로 점검하면 퀴즈 보기 순서와 길이 단서 주의 256건, 목표 칩 「 · 」 오류 3건(u1-ai-principle, u1-ai-problem, u4-process)이 나옵니다.
> 지금 학기 수업 중이라 그대로 두었습니다. 다음 학기 미리보기 검토 때 같이 고치면 됩니다.

## 매 학기

1. **진도 수집 시트**: 메뉴 「📈 진도 현황 → 새 학기 시작」을 누르면 지난 기록이 `보관_…` 탭으로 옮겨집니다. 「질문응답」·「질문현황」 탭도 함께 옮겨집니다.
2. **명단**: 새 「명단」 탭에 반 · 학번 · 이름을 붙여넣습니다. 학생은 학번·이름만 넣고, 반은 여기서 찾습니다.
3. **교사 코드**: 바꾸려면 「교사 코드 정하기」를 누릅니다.
4. **질문폼**: 반 선택 칸을 쓰고 싶을 때만 `forms/forms.json`의 `classes`에 반 이름을 넣습니다. 비워 두면 명단에서 반을 찾습니다.
5. **차시 운영표**: `course.json`에서 이번 학기 차시 번호와 순서를 정하고, 공개할 차시를 `ready`로 바꿉니다.
6. **수행평가**: `assessments/ideas/`에서 고르고, 이번 학기 안내 페이지를 만듭니다.
7. **산불 사진(Ⅳ 비정형 프로젝트)**: 사진 저작권 때문에 저장소에 넣지 않았습니다.
   - 작업 폴더 `코스웨어_자료/fire.zip`을 구글 드라이브에 올리고, 공유를 「링크가 있는 모든 사용자 · 뷰어」로 합니다.
   - 지금 공유 폴더 주소가 두 노트북 첫 셀 `ZIP_URL`에 미리 들어 있습니다. 학생은 실행만 하면 됩니다.
   - 드라이브 폴더를 지우거나 공유를 끄면 실습이 멈추니 그대로 유지합니다.
   - 다른 곳에 다시 올리면 두 노트북의 `ZIP_URL`만 바꾸면 됩니다. 폴더 주소와 파일 주소 모두 됩니다.
   - 학교 계정이 외부 공유를 막으면 개인 계정으로 올립니다.
8. 빌드 → 점검 → push → 선생님 목록(`/teacher/`)에서 차시 열어 보기
